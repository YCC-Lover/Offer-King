## 这版有什么变化

- **快速查找：** 顶部入口或 `Ctrl+K` 搜索本机公司、岗位和页面；支持公司别名、城市、技能、阶段、多关键词与键盘选择。只查本机，不联网搜索或调用 AI；明确搜索时可找到带归档标记的历史记录。
- **看板／列表双视图：** 同一份岗位资料，按阶段拖动或每页 30 条集中浏览。列表保持表头、身份列可见，支持独立双向滚动、阶段选择和快速跟进。
- **组合筛选与常用视图：** 阶段、优先级、城市、办公方式、收藏、待办六类筛选，配合更新、提醒、优先级排序。最多保存 12 个本机命名视图，应用、更新和删除均为明确操作。
- **快速跟进：** 首页、看板、全部待办都可安排明天、下周同日、自定时间或暂不安排时间。明确保存后只更新改过的事项／日期，写入流程，不改变阶段；同字段冲突会提示核对，不用旧值覆盖新值。
- **首页与详情更清楚：** 已有记录时优先待办；没有 Offer 时显示正在推进的岗位。Offer、岗位资料、共享公司资料和联系人按需展开，折叠不清除当前草稿，保存仍需确认。
- **小屏、大字号与键盘优化：** 可滚动筛选工具栏、手机紧凑布局、输入法 Esc 保护及详情标签键盘操作。手机“开发预览与备份”工具移到“帮助与关于”，保留快照导出。
- 中／英／日／韩界面继续可用，保留 90%–125% 字号、浅／深色主题、公司风险与排行、Offer 比较、本机招聘识别、到手工资、预算和备份。

## 第一次使用与 AI 配置

先用虚构公司和岗位试一遍“新增 → 保存 → 快速跟进 → 关闭重开 → 导出备份”。新增效率功能、本机招聘识别和到手工资都不需要 AI。设备各自保存，不自动同步。

需要 AI 时进入“设置与备份 → AI 调研”：

1. **免费起步预设：** 自备 OpenRouter 模型密钥与 Tavily 搜索密钥，保存并启用，再按费用提示测试。没有共享 Key，不保证永久免费或始终可用。
2. **自己的模型：** 填兼容协议、HTTPS 基础地址、准确模型名和自己的密钥，保存后明确设为默认或指定任务。普通模型联网另需 Tavily；原文提取只需岗位模型。
3. **原有百炼／DeepSeek：** 保留已有策略。本包官方 DeepSeek 岗位／风险联网只支持主动选择 Pro；包中旧 Flash 模型 ID 的服务端可用性需核对官方文档，未用真实凭据实测。不要把模型连通当成搜索成功。
4. **核对后保存：** “创建岗位后自动调研”默认关闭；主动启用才在新建成功后调用。AI 建议进入草稿，仍需核对证据并明确保存，不自动改变个人求职状态。

Windows 密钥使用平台安全存储，Android 使用 Keystore；不进入业务 JSON。手机 localhost 指手机本身，不是电脑上的 Ollama。云端原文提取会发送你粘贴的文字，先去除私人信息。模型、搜索和测试可能计费。[完整 AI 配置与排错](AI-SETUP.md)
