## 四个值得试的新功能

### 1. 全部待办，不漏掉七天之后

“全部待办”提供 **逾期、今天、未来七天、以后、待安排时间** 五组，长列表可完整滚动。可以直接完成事项，或打开岗位详情调整时间。

完成事项会写入流程记录并清除对应下一事项，不自动改变求职阶段。归档、已拒绝、已结束的岗位不进入待办；公司单独归档不会隐藏仍活跃的岗位事项。提醒仍在 App 内，不是关闭 App 后运行的系统闹钟。

### 2. PK 与城市预算，异常退出后继续写

未保存的 Offer PK 与城市预算纳入本机恢复草稿，尚未完成的新方案也可以找回。重启后从首页查看、预览，再恢复到对应表单；核对后仍需明确点击保存。

已保存记录更新、删除或关联资料改变时会提示，不用旧草稿静默覆盖最新结果。暂存最多 10 份、约 1 MiB，不是正式备份，也不保证保住断电前最后瞬间的输入；出现失败请留意提示。

### 3. 粘贴招聘原文，不必额外配置搜索

岗位详情的 AI 面板增加 **“粘贴招聘原文”**。从招聘软件或官网复制同一岗位的介绍，核对模型、删除个人信息并同意隐私与费用后，即可提取职责、要求、技能、薪资和福利。

- 只调用已保存的岗位模型，不调用 Tavily，不访问原文中的网址，不自动切换其他服务。支持兼容模型及本机 Ollama；原有岗位路线只使用 DeepSeek，只有百炼配置不能执行此任务。
- 只建议有原文证据的岗位及薪酬字段，不猜未知待遇，不生成公司共享资料或风险结论，不伪造网页来源。
- **全部建议默认不选**。主动勾选后加入可编辑草稿，再核对并保存；未采纳建议不会因点击保存自动写入。
- 结果标记 **“用户提供招聘原文，未经联网核实”**。它是提取工具，不证明招聘信息真实有效或构成雇主承诺。
- 云端模型会收到粘贴的文字；完整原文仅在窗口内存中保留，但**已采纳字段与有限证据摘录可以随草稿保留，正式保存后可进入记录和备份**。

### 4. AI 一键检查，知道下一步该改哪里

设置中的“AI 一键检查”依次检查 **已保存配置 → 模型连接与结构化输出 → 联网来源**。针对的是岗位联网补全当前实际路线，不是尚未保存的设置，也不是所有任务的一次性认证。

缺配置时只做本地检查。配置齐全并明确同意费用后，最多发送一次模型测试与一次对应搜索测试，使用固定测试文字，不使用你的公司、岗位、联系人或附件。失败即停止，支持取消，不自动重试或改换服务；已发送请求可能消耗额度。通过不保证真实网页可读取、资料准确或之后额度始终充足。

## AI 怎么开始？

1. **先用本地功能也可以。** 手动记录和比较不需要 AI。
2. **只想提取已有原文：** 配置一个支持结构化输出的岗位模型，或已准备好模型的本机 Ollama；不要求 Tavily。
3. **想联网查询：** 可用“免费 AI 起步”配置自己的 OpenRouter 与 Tavily 密钥，或使用自己的兼容模型＋搜索服务。原有百炼／DeepSeek 配置和任务策略继续保留。
4. 保存并明确启用模型后，再检查实际路线。创建岗位后自动调研默认关闭，愿意启用时才打开并保存；自动调研失败不会删除新建记录。

没有内置共享密钥，不承诺免费额度或服务可用性。测试、原文提取、搜索与调研可能消耗额度，取消不能撤销服务商已处理的费用。兼容协议不保证任意模型都支持所需结构化输出。[完整配置与费用说明](https://github.com/YCC-Lover/Offer-King/blob/main/docs/AI-SETUP.md)

## 升级与数据边界

旧用户先在原版本手动导出 JSON，另行保管附件原文件，再关闭旧版。版本设计保留原安装身份、数据位置和备份格式，不迁移或清空公司、岗位、风险、评分、附件路径或 AI 配置。但**真实安装器覆盖流程尚未验收**，愿意试用时请保留原安装位置与升级前备份，异常时不要清空资料。

没有新增云同步、遥测、共享密钥或后台付费任务。API Key 通过 Windows 安全存储加密，不进入求职 JSON 备份；普通记录和草稿不是加密保险箱。附件仍只保存路径，JSON 不包含附件文件本身。详见[数据与隐私说明](https://github.com/YCC-Lover/Offer-King/blob/main/docs/PRIVACY.md)。

只向朋友分享发布页、安装包和指南，不分享自己的数据目录、备份或密钥。每位使用者配置自己的 AI 服务。没有自动更新；[上一版 2.1.1 发布页](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.1.1) 继续保留。
