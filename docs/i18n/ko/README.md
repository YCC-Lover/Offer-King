## 지원부터 최종 선택까지

여러 회사의 지원 현황을 관리하거나, 오퍼를 비교하거나, 이사까지 고민하는 분을 위한 도구입니다.

- **지원마다 다음 단계를 놓치지 않게.** 단계별 보드, 면접 기록, 다음 할 일과 날짜를 정리합니다. 같은 회사의 여러 직무도 독립적으로 관리합니다.

- **입력은 줄이고 확인은 직접.** 공고를 붙여 넣어 기기에서 인식한 근거를 확인한 뒤 선택한 빈 항목만 채웁니다. 기존 입력과 재사용하는 회사의 공통 정보는 유지하며, 모호한 정보는 추측하지 않습니다.

- **나에게 중요한 조건으로 비교.** 통상 연간 보상과 첫해 총보상을 구분하고, 두 오퍼를 자신의 우선순위로 비교합니다.

- **실수령액 미리 계산.** 중국 본토 CNY 급여의 사회보험·주택공적금·소득세와 12개월 실수령액을 추정합니다. 원래 직무의 급여 정보는 바꾸지 않습니다.

- **이사 후 생활까지 계획.** 월세, 출퇴근 비용, 생활비를 직접 입력해 예상 저축액을 비교합니다. 실시간 지역 시세가 아니라 본인의 가정에 따른 예산입니다.

- **판단의 근거를 한곳에.** 기업 정보, 출처가 있는 리스크 조사, 개인 기업 상위 3개 순위를 함께 살펴봅니다. 점수는 의사결정 참고값이며 객관적인 기업 등급이 아닙니다.

## 세 단계로 시작하세요

1. **다운로드하고 확인하기.** 위에서 Windows 앱 또는 Android 체험판을 고른 뒤 [다운로드 안내](DOWNLOAD.md)를 따라 진행하세요. 공개 파일을 받는 데 GitHub 계정이나 개발 도구는 필요하지 않습니다.

2. **첫 지원 기록 만들기.** UI 언어를 고르고 회사·직무를 입력하거나, 공고를 붙여 넣어 오프라인 미리보기를 확인하세요. 도시와 단계를 확인하고 필요하면 기존 회사를 재사용합니다. 다음 할 일이 정해지면 날짜도 남겨 두세요.

3. **저장하고 백업하기.** 필요한 정보를 조금씩 추가해 명시적으로 저장하고, JSON을 정기적으로 내보내세요. 첨부 원본은 따로 보관합니다. AI는 나중에 설정해도 됩니다.

언어는 즉시 바뀌고 이 기기에 기억합니다. **회사명·직무명·메모·직접 정한 단계 이름은 번역하지 않습니다.** 편집 중인 입력도 유지하며, 언어 설정은 지원 데이터 백업에 포함하지 않습니다.

## Android 2.6.1 체험판에서 달라진 점

- **앱에서 다음 체험판 확인.** 도움말 및 정보 → 앱 업데이트에서 수동 확인하고, 자동 확인을 켜면 전면 사용 중 최대 24시간에 한 번 확인합니다. 후보 버전 포함이 필요하며 무시한 버전 설정도 유지합니다. 알림으로 공식 릴리스 페이지를 열고 다운로드와 설치는 직접 선택합니다.
- **2.6.0 이하는 처음 한 번 수동 업데이트.** 기존 Android 체험판은 체험 APK 파일 이름을 인식하지 못합니다. 2.6.1을 기존 앱 위에 업데이트해야 수정된 확인 기능을 얻습니다. 이전 APK에 원격으로 기능을 추가할 수는 없습니다.
- **기존 기록과 AI 설정을 유지하는 설계.** 앱 ID, 데이터 원본, AI 저장소와 2.6.0 Debug 서명을 유지합니다. 먼저 JSON을 앱 밖에 내보내고 첨부 원본을 별도로 보관하세요. 앱 제거·데이터 삭제·AI 설정 초기화는 하지 마세요. JSON에는 키와 첨부 원본이 없습니다. 실기기 첫 설치·덮어쓰기·암호화 키 유지 검증은 미완료이며 서명 충돌 시 중단하세요.
- **다크 모드 업데이트 안내 개선.** 글자 대비를 높였습니다. 버전 확인은 AI를 호출하거나 기록·키를 보내지 않으며 AI 요금도 없습니다. 기존 AI 설정과 경로는 바꾸지 않습니다.

## 2.6.0에서 이어지는 기능

- **기록을 더 빨리 찾기.** 헤더 또는 `Ctrl/Cmd + K`에서 페이지·회사·직무를 기기 내에서 검색하고 키보드로 열 수 있습니다.
- **보드와 목록 전환.** 단계·우선순위·도시·근무 방식·즐겨찾기·할 일의 6가지 필터를 조합하고 정렬해 **이름 있는 보기 최대 12개**를 저장합니다. 목록은 **페이지당 30개**이며, 보기에는 표시 조건만 저장하고 기록 사본이나 검색어는 넣지 않습니다.
- **다음 할 일을 바로 수정.** 보드·목록·알림에서 내용과 날짜를 바꾸고 명시적으로 저장합니다. 변경 내역은 전형 기록에 남으며 지원 단계는 자동 변경하지 않습니다.
- **오늘 할 일에 집중.** 간결해진 홈에서 알림을 먼저 보고, 상세의 보조 항목은 필요할 때 펼칩니다. 모바일의 큰 글자·스크롤·고정 버튼 영역도 개선했습니다.

이 새 기능들은 로컬에서 작동하며 AI를 호출하지 않습니다. 자동 조사는 계속 기본적으로 꺼져 있습니다. **단위·컴포넌트 테스트 1,280개**, **Node 314개**(4개 건너뜀), **패키지 Electron 시나리오 5개**, **가상 데이터로 압축 해제된 2.5.4 → 2.6.0 앱을 전환하는 업그레이드 시나리오 1개**가 통과했습니다. Android 컴파일과 정적 패키지 점검은 완료했지만 브라우저 터치·화면 검증은 휴대폰 실기기 검증이 아닙니다. 실제 Windows 설치와 Android 실기기 인수 검증은 아직 완료하지 않았습니다.

## AI는 필요할 때 선택하세요

**AI 없이 먼저 시작할 수 있습니다.** 필요한 작업에 맞춰 고르세요.

1. **오프라인·설정 불필요:** 로컬 기록, 빠른 입력, 실수령액 추정에는 모델·키·네트워크가 필요 없고 AI 요금도 없습니다.

2. **모델만으로 원문 추출:** 이미 가지고 있는 채용 공고를 설정한 호환 모델로 분석합니다. 지원 환경에서는 준비된 로컬 Ollama도 선택할 수 있습니다. 웹 검색이나 원문 사실 확인은 하지 않으며 검색 키도 필요하지 않습니다.

3. **모델 + 검색으로 조사:** 지원 모델과 필요한 검색 경로를 설정해 공개 기업·직무 정보를 조사합니다. OpenRouter + Tavily 시작 프리셋도 **본인의 계정과 키**가 필요합니다.

**공유 API 키가 포함되어 있지 않으며, 무료 클라우드 사용량도 보장하지 않습니다.** 모델 호출·검색·연결 테스트는 사용량을 차감하거나 요금이 발생할 수 있습니다. 제공 여부와 호환성은 서비스에 따라 다릅니다. 기존 Bailian(百炼)·DeepSeek 설정과 플랫폼별 제한은 [AI 설정 안내](AI-SETUP.md)를 확인하세요.

지원 생성 후 자동 조사는 **기본적으로 꺼져 있습니다**. 출처와 날짜를 확인하고 제안 중 원하는 항목을 초안에 반영한 뒤 **명시적으로 저장**하세요. AI 출력은 검증된 사실이 아니며, 기록을 알리지 않고 덮어쓰지 않습니다.

## 자주 묻는 질문

<details>
<summary><strong>계정이나 AI 없이 오프라인으로 사용할 수 있나요?</strong></summary>

네. 로컬 기록, 단계, 전형 기록, 다음 할 일, 비교, 예산, JSON 백업에는 앱 계정이나 AI가 필요하지 않습니다. 클라우드 동기화와 공동 작업은 제공하지 않습니다. 알림은 앱 안에 표시되며 앱을 닫은 뒤에도 작동하는 시스템 알람은 아닙니다. 기업 아이콘과 AI 기능은 네트워크를 사용할 수 있습니다.

</details>

<details>
<summary><strong>한국 등 다른 나라의 세금·실수령액도 계산하나요?</strong></summary>

아니요. 중국 본토 거주자 개인이 1월부터 같은 직장에서 고정 월급을 12개월 받는 CNY 급여를 추정합니다. 도시별 실제 산정 기준액과 비율을 직접 지정하며, 베이징 참고 템플릿도 명시적으로 선택해야 적용됩니다. 국제 급여 계산이나 세무 자문이 아니며 외화를 자동 환산하지 않습니다. 결과는 직무나 도시 예산에 다시 저장하지 않습니다.

</details>

<details>
<summary><strong>무엇을 백업하고, 친구에게는 무엇을 공유해야 하나요?</strong></summary>

설치 파일이나 프로젝트 링크만 공유하고 개인 데이터 폴더·백업은 공유하지 마세요. 설치 파일에 작성자의 기록이나 키는 없으며 각자 빈 로컬 기록으로 시작합니다. 키는 플랫폼 보안 저장소로 보호하고 지원 데이터 JSON에는 넣지 않습니다. 다만 기록·복구 초안·백업 자체는 **암호화 금고가 아닙니다**.

JSON 백업에는 **첨부 원본 파일이 포함되지 않습니다**. Windows는 로컬 경로, Android는 기기별 문서 접근 권한을 사용하며 이 권한은 백업과 함께 다른 기기로 옮겨지지 않습니다. 원본을 따로 보관하세요.

클라우드 추출은 붙여 넣은 원문을 선택한 모델로 전송합니다. 전체 원문은 메모리에만 있지만 채택한 항목과 제한된 근거 발췌문은 초안·기록·백업에 남을 수 있습니다. 보내기 전에 개인정보를 제거하세요. [개인정보 안내(중국어)](../../PRIVACY.md)

</details>

<details>
<summary><strong>업데이트 방법과 지원 플랫폼·언어는 무엇인가요?</strong></summary>

Windows 2.5.4 이상은 전면 사용 중 수동 확인하고 자동 확인을 켜면 최대 24시간에 한 번 확인합니다. Windows 2.6.0 안내에는 **후보 버전 포함**을 켜야 하며 2.4.0 이하는 먼저 수동 업데이트하세요. **Android 체험판 2.6.0 이하도 처음 한 번 직접 2.6.1로 업데이트해야 합니다.** 이후 도움말 및 정보 → 앱 업데이트에서 미래의 더 높은 공식 체험 APK를 확인할 수 있습니다. 후보 포함·자동 확인 끄기·버전 무시 설정을 존중하며 **자동 다운로드·설치는 하지 않습니다**. 서명이 충돌하면 중단하고 기존 데이터를 지워 해결하지 마세요. [백업·업데이트 안내](DOWNLOAD.md)

공개 체험판은 Windows 10 / 11 x64와 Android 7.0 이상에서 간체 중국어·영어·일본어·한국어 UI를 지원합니다. 실기기 인수 검증은 미완료입니다. macOS·iOS·Linux 설치 파일이나 포터블 버전은 없습니다. 최소 창 1100 × 700은 Windows에만 적용됩니다.

</details>
