## 지원부터 최종 선택까지

- **여러 회사에 지원해도 놓치지 않게.** 단계별 보드와 전형 기록으로 진행 상황을 정리하고, 직무마다 다음 할 일과 시간을 남길 수 있습니다. 같은 회사의 여러 직무도 각각 관리합니다.
- **붙여 넣어 입력 줄이기.** 지원 추가에서 한 채용 공고의 명확한 항목을 기기에서 인식하고, 원문 근거를 확인한 뒤 선택한 빈 항목만 채웁니다. AI나 인터넷을 사용하지 않습니다.
- **처우와 나의 우선순위를 함께 비교.** 통상 연간 보상과 첫해 총보상을 구분합니다. 두 오퍼 비교에서는 급여, 성장, 워라밸 등 나에게 중요한 항목에 직접 가중치를 줄 수 있습니다.
- **실수령액 미리 계산.** 중국 본토의 개인 사회보험·주택공적금, 소득세와 12개월 급여 내역을 살펴봅니다. 원래 채용 기록의 급여는 바뀌지 않습니다.
- **이사 후 생활까지 계획.** 세후 현금 수입, 월세, 출퇴근 비용, 생활비를 입력해 예상 저축액을 비교합니다. 실시간 지역 평균 물가나 자동 세금 계산이 아니라 개인 입력에 따른 예산입니다.
- **판단의 근거를 남기기.** 기업 정보, 출처가 있는 리스크 조사, 개인 기업 순위, 급여 분석을 함께 볼 수 있습니다. 점수는 나의 판단을 돕는 참고값이며 객관적인 기업 등급이 아닙니다.

## 세 단계로 시작하세요

1. **다운로드하고 파일 확인.** [다운로드 안내](DOWNLOAD.md)를 따라 진행하세요. 공개 설치 파일을 받는 데 GitHub 계정이나 개발 도구는 필요하지 않습니다.
2. **언어를 고르고 첫 지원 기록 저장.** 사이드바 또는 설정 및 백업 → 화면 및 가독성에서 언어를 고르세요. 지원 추가에서 회사·직무를 직접 입력하거나 공고를 붙여 넣어 오프라인 인식 결과를 확인하세요. 도시·단계를 확인하고 필요하면 기존 회사를 선택한 뒤 기록을 만듭니다. 다음 할 일이 정해지면 시간도 함께 적으세요.
3. **필요한 정보부터 조금씩.** 처우를 알게 되면 보상 정보를 채우고 오퍼와 생활 예산을 비교하세요. JSON 백업을 정기적으로 내보내고, 첨부 원본 파일은 따로 보관하세요.

언어는 즉시 바뀌고 이 기기에 기억합니다. 편집 중인 입력은 유지하며 회사명·직무명·메모·직접 정한 단계 이름은 번역하지 않습니다. 언어 설정은 지원 데이터 백업에 포함되지 않습니다. AI는 나중에 설정해도 되며 기록·할 일·비교·백업은 AI 없이 사용할 수 있습니다. 이전 스크린샷과 [자세한 사용법(중국어)](../../QUICKSTART.md)는 중국어 표시를 사용합니다.

## 2.5.4 체험판에서 달라진 점

- **두 플랫폼의 체험판:** 도움말에 체험판 표시와 OS별 서명·미검증 범위를 안내합니다. Android 개발 체험판은 문서 접근과 기업 공식 사이트 아이콘을 지원하지만 실제 기기 동작은 추가 검증이 필요합니다.
- **Windows 새 버전 안내:** 자동 확인을 켜면 앱이 열려 있고 전면에 있을 때 하루 한 번 새 버전을 확인할 수 있습니다. 수동 확인과 공식 릴리스 페이지 열기도 제공하며 업데이트를 자동으로 받거나 설치하지 않습니다. 2.4.0 이하는 먼저 한 번 수동으로 업데이트해야 합니다. Android Debug 체험판은 정식 자동 업데이트 경로로 권장하지 않습니다.

2.4.0의 로컬 도구도 계속 사용할 수 있습니다.

- **오프라인 빠른 입력:** 같은 회사·직무의 공고를 최대 50,000자까지 붙여 넣고 회사명, 직무, 도시, 링크, 급여 등 명시된 항목의 근거를 확인해 빈 항목을 채웁니다. 기존 입력이나 재사용하는 회사의 공통 정보는 덮어쓰지 않고, 모호한 정보는 추측하지 않습니다. 전체 원문은 현재 창의 메모리에만 있으며 복구 초안·백업에 넣지 않습니다. 모델·키·네트워크가 필요 없고 AI 요금도 없습니다.
- **실수령 급여 계산:** 중국 본토 거주자 개인이 1월부터 같은 직장에서 고정 월급을 12개월 받는 CNY 급여를 기기에서 추정합니다. 원하는 도시와 실제 보험료 산정 기준액·비율을 입력할 수 있습니다. 현재 검증된 참고 템플릿은 베이징뿐이며 직접 적용해야 사용됩니다. 개인 부담금, 세금, 월별·연간 실수령액을 보여 주지만 급여 명세서나 세무 자문은 아닙니다. 채용 기록·도시 예산에 다시 저장하지 않고 외화도 자동 환산하지 않습니다.

2.3.0의 언어 기능도 계속 사용할 수 있습니다.

- **4개 UI 언어:** 사이드바나 화면 설정에서 简体中文·English·日本語·한국어를 재시작 없이 바꿉니다.
- **입력과 원문 유지:** 표시 언어를 바꿔도 편집 내용과 회사명·직무명·메모·사용자 단계 이름은 유지합니다. 기본 단계는 표시만 번역하고 저장된 이름은 바꾸지 않습니다.
- **다국어 안내:** 홈, 다운로드, AI 설정 문서를 네 언어로 제공합니다.

2.2.0의 일상 관리 기능도 계속 사용할 수 있습니다.

- **할 일을 빠짐없이:** 기한 지남, 오늘, 앞으로 7일, 이후, 시간 미정의 다섯 그룹을 제공합니다. 완료하면 전형 기록을 남기고 다음 할 일을 지우며, 지원 단계는 바꾸지 않습니다.
- **초안 복구:** 예기치 않게 종료된 뒤 두 오퍼 비교와 도시 예산 초안을 미리 보고 복원한 다음 직접 저장할 수 있습니다.
- **채용 원문 추출:** 붙여 넣은 소개에서 원문 근거를 확인하며 항목을 선택합니다. 웹 검색이나 온라인 사실 확인은 하지 않습니다.
- **AI 설정 점검:** 사용량과 요금 안내에 동의한 뒤 저장된 직무 모델과 검색 경로를 점검합니다.

## AI는 필요할 때 선택하세요

AI는 선택 기능입니다. 오프라인 빠른 입력과 실수령액 계산은 모델을 사용하지 않으며 AI 요금이 없습니다. **공유 API 키가 들어 있지 않으며, 무제한 무료 클라우드 AI를 제공하지 않습니다.**

- 가지고 있는 채용 원문을 추출하려면 호환 직무 모델 또는 준비된 로컬 Ollama 모델을 설정하세요. 이 작업에는 검색 키가 필요하지 않습니다.
- 공개 정보를 온라인으로 조사하려면 모델과 필요한 검색 서비스를 설정하세요. 무료 시작 프리셋도 본인의 OpenRouter·Tavily 계정과 키가 필요합니다. 제공량과 사용 가능 여부는 각 서비스에 따릅니다.
- 기존 Bailian(百炼)·DeepSeek 설정도 유지됩니다. 모델 호출, 검색, 연결 테스트는 사용량을 차감하거나 요금이 발생할 수 있습니다.

새 지원 생성 후 자동 조사는 기본적으로 꺼져 있습니다. AI 제안은 직접 확인하고 명시적으로 저장하세요. [한국어 AI 설정 안내](AI-SETUP.md)

## 자주 묻는 질문

<details>
<summary><strong>AI 없이, 오프라인으로도 사용할 수 있나요?</strong></summary>

네. 로컬 기록, 오프라인 빠른 입력, 실수령액 계산, 단계, 전형 기록, 할 일, 비교, 예산, 백업에는 AI가 필요하지 않습니다. 알림은 앱 안에서 표시되며, 앱을 닫은 뒤에도 작동하는 시스템 알람은 아닙니다. 기업 홈페이지 아이콘과 AI 기능은 인터넷을 사용할 수 있습니다.

</details>

<details>
<summary><strong>친구에게 설치 파일을 주면 내 기록도 전달되나요?</strong></summary>

아니요. 설치 파일에는 작성자의 지원 기록이나 키가 없습니다. 각자 기기에서 본인의 기록을 만들고 AI도 직접 설정합니다. 설치 파일이나 프로젝트 링크만 공유하고, 개인 데이터 폴더나 백업은 공유하지 마세요.

API 키는 각 플랫폼의 기기 내 보안 저장소로 보호하며 지원 데이터의 JSON 백업에 넣지 않습니다. 일반 기록, 복구 초안, 백업 자체는 암호화 금고가 아닙니다. Windows 첨부는 로컬 경로, 모바일 첨부는 기기별 문서 접근 권한을 사용합니다. 백업에는 첨부 원본이 없으며 다른 기기로 접근 권한을 이전하지도 않습니다.

클라우드 모델로 원문을 추출하면 붙여 넣은 내용이 해당 모델로 전송됩니다. 전체 원문은 현재 창의 메모리에만 있지만, **채택한 항목과 제한된 근거 발췌문은 초안·기록·백업에 남을 수 있습니다**. 전송 전에 개인정보를 지워 주세요. [개인정보 안내(중국어)](../../PRIVACY.md)

</details>

<details>
<summary><strong>한국어 UI나 다른 운영체제도 지원하나요?</strong></summary>

2.5.4 후보 버전은 Windows 10 / 11 x64와 Android 개발 체험판(Android 7.0 이상, 실기기 인수 검증 미완료)에서 간체 중국어·영어·일본어·한국어를 지원합니다. 탐색 메뉴나 화면 설정에서 즉시 바꾸고 기기에 기억합니다. 최소 창 1100 × 700은 Windows에만 적용하며 Android 조건이 아닙니다. macOS·iOS·Linux 설치 파일, 포터블 버전, 클라우드 동기화, 공동 작업은 없습니다.

</details>

Windows 2.5.4는 **전면 실행 중 새 버전 확인과 공식 페이지 열기**를 제공하지만 자동 다운로드·설치는 하지 않습니다. [2.5.4 릴리스 페이지](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.5.4)를 읽고 백업한 뒤 수동으로 설치하세요. 2.4.0 이하는 알림 기능을 받기 위해서도 먼저 한 번 수동 업데이트해야 합니다. Android Debug 체험판은 다운로드 안내에 따라 수동으로 다루고 정식 자동 업데이트 채널로 취급하지 마세요. GitHub Watch는 앱 알림과 별개입니다.
