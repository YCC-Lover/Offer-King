**Android 2.6.1 / Windows 2.6.0 소규모 체험 후보 버전(Pre-release)** 안내입니다. 2.6.1은 Android만 업데이트하며 AI 설정·경로는 그대로입니다. 체험 기간 만료나 별도의 기능 잠금은 없습니다. 사이드바나 화면 설정에서 간체 중국어·영어·일본어·한국어를 즉시 바꿀 수 있으며 입력 중인 내용은 유지합니다. [다운로드 및 파일 확인](DOWNLOAD.md) · [Android 2.6.1 릴리스](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.6.1) · [Windows 2.6.0 릴리스](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.6.0)

이전 화면과 비교할 수 있도록 아래 단계에 중국어 메뉴도 함께 표기했습니다. 표시 언어를 바꿔도 기록을 번역하거나 AI 제공자·키·모델·검색 경로·요금 동의를 변경하지 않습니다.

지원 관리, 할 일, 오퍼 비교, 백업은 AI 없이도 됩니다. AI는 본인의 계정과 키로 사용하는 선택 기능이며 사용량을 차감하거나 요금이 발생할 수 있습니다. **공유 키나 무제한 무료 서비스는 포함되지 않습니다.**

새 설치는 빈 데이터로 시작합니다. Android 2.6.1은 기존 앱 ID·데이터 원본·서명·AI 저장소를 유지하는 설계지만 실기기에서 유지되는지는 미검증입니다. 편집 내용을 저장하고 앱 밖으로 JSON을 내보낸 뒤 **앱 제거·데이터 삭제·AI 설정 초기화 없이 기존 앱에 업데이트**하세요. 다시 열어 기록과 AI 설정 상태를 확인하고 서명 충돌 시 중단·신고하세요. JSON에는 API 키와 첨부 원본이 없어 제거 후 키를 복구할 수 없습니다. 클라우드 동기화나 작성자의 기록·키는 포함하지 않습니다. 해당 버전의 `START-HERE.md`, `SHA256SUMS.txt`, `TEST-RESULTS.json`에서 파일과 검증 범위를 확인하세요.

## AI 없이 시작하기

**2.6.0의 작업 편의 기능에는 AI가 필요 없습니다.** 빠른 찾기, 보드·목록, 조합 필터, 저장한 보기, 다음 할 일 빠른 수정은 로컬에서 동작합니다. 기존 AI 설정과 자동 조사 선택은 유지하며 신규 사용자의 자동 조사는 기본적으로 꺼져 있습니다. 다음 할 일을 수정해도 조사가 시작되지 않습니다. [새 기능(중국어)](../../RELEASE-2.6.0.md)

**지원 추가 → 채용 공고 붙여넣기**의 기기 내 인식으로 명시된 회사·직무·도시·링크·급여를 미리 보고 빈 항목에 넣을 값을 고르세요. 기존 입력이나 재사용하는 회사의 공통 정보는 바꾸지 않으며 모호한 사실은 추측하지 않습니다. 통화가 없는 금액은 기본 미선택입니다. 전체 원문은 현재 창의 메모리에만 있고 복구 초안·백업에 저장하지 않습니다. 아래의 AI 원문 추출과는 별개로 키·네트워크·AI 요금이 필요 없습니다.

**실수령 급여**도 모델 없이 기기에서 계산합니다. 중국 본토 거주자 개인이 1월부터 같은 직장에서 고정 월급을 12개월 받는 CNY 급여를 대상으로 합니다. 원하는 도시와 실제 기준액·비율을 입력할 수 있으며 현재 검증된 참고 템플릿은 베이징뿐으로 직접 적용해야 합니다. 채용 보상·도시 예산에 다시 저장하지 않고 외화를 환산하지 않습니다. 급여 명세서나 세무 자문이 아닌 추정치이며 AI 요금이 없습니다.

## 1. 먼저 필요한 작업을 고르세요

| 하려는 작업 | 필요한 설정 | 웹 검색 여부 |
| --- | --- | --- |
| 지원 생성 전 명시된 항목 인식 또는 실수령액 계산 | 없음. 로컬 도구 | AI·네트워크 호출 없음 |
| AI로 붙여 넣은 원문에서 더 많은 항목 추출 | 호환 직무 모델 또는 준비된 로컬 Ollama 모델 | 검색 안 함. Tavily 불필요 |
| 회사·직무의 공개 정보 조사 | 호환 모델＋본인 Tavily 키 또는 기존 제공자 경로 | 검색함. 출처 확인 필요 |
| 로컬 기록·할 일·비교·백업 | 없음 | AI 호출 없음 |

원문 추출은 **온라인 사실 확인이 아닙니다**. 일반 모델에 API 키를 입력한다고 검색 기능이 저절로 생기지는 않으며, 연결 성공도 검색과 구조화 추출의 성공을 보장하지 않습니다. 회사 홈페이지 아이콘과 버전 확인은 별도 네트워크 기능이므로 로컬 인식을 쓴다고 앱 전체가 인터넷에 전혀 접속하지 않는다는 뜻은 아닙니다.

## 2. 무료 시작 프리셋

1. **设置与备份 → AI 调研 → 免费 AI 起步**(설정 및 백업 → AI 조사 → 무료 AI 시작)를 엽니다.
2. [OpenRouter](https://openrouter.ai/settings/keys)에서 본인 키를 만들어 “OpenRouter 免费模型 API Key”에 입력합니다. 프리셋은 `https://openrouter.ai/api/v1`의 `openrouter/free`를 사용합니다.
3. [Tavily](https://app.tavily.com/home)에서 본인 검색 키를 받아 “免费起步 Tavily API Key”에 입력합니다. 무료 제공량 안에서만 쓰려면 두 서비스의 현재 한도와 요금 설정을 확인하세요.
4. **保存并启用免费配置**(무료 설정 저장 및 활성화)를 누릅니다. 회사·직무·리스크 세 작업을 이 프리셋으로 명시적으로 전환합니다. 저장만으로 조사를 시작하지는 않습니다.
5. 모델과 검색을 각각 테스트하거나, 요금 안내를 확인한 뒤 한 번에 점검합니다. 테스트도 사용량을 차감할 수 있습니다.

무료 프리셋은 가격이 0인 제공자만 요청하도록 제한하며 실패해도 유료 모델로 몰래 바꾸지 않습니다. 모델 가용성과 한도는 달라질 수 있고 고정 제공량이나 영구 무료는 보장하지 않습니다. Tavily는 채팅 모델이 아니라 검색 서비스이며 모델과 별도의 한도·요금이 있습니다. 이 경로의 새 조사 한 번은 basic 검색을 최대 한 번 수행하고 검색 깊이를 자동으로 높이지 않습니다. 아직 유효한 후보를 선택하면 첫 검색의 근거를 재사용합니다. 서비스 계정의 과금 설정은 본인이 관리하세요. [OpenRouter 무료 라우터 안내](https://openrouter.ai/docs/guides/routing/routers/free-router)와 [Tavily 사용량 안내](https://docs.tavily.com/documentation/api-credits)를 확인할 수 있습니다.

“创建岗位后自动调研”(지원 생성 후 자동 조사)은 **기본적으로 꺼져 있습니다**. 사용하려면 켠 뒤 “保存自动调研偏好”로 저장하세요. 새 지원이 성공적으로 생성된 뒤 한 번 호출하며, 입력 중이나 기존 지원을 열 때 자동 실행하지 않습니다.

## 3. 본인 모델 설정하기

**我的模型配置 → 新增模型配置**(내 모델 설정 → 모델 추가)에서 이름, 프로토콜, 기본 URL, 정확한 모델 ID, 해당 API 키를 입력합니다. OpenAI 호환 Chat Completions, Responses, 로컬 Ollama 경로를 지원하지만, 모델과 서비스가 앱에 필요한 구조화 출력을 지원해야 합니다. 채팅 웹사이트의 유료 구독이 API 사용량을 포함하는 것은 아닙니다.

클라우드 주소는 공개 HTTPS여야 하며 저장 전 인식된 기본 주소를 확인하세요. “读取模型列表”로 모델 목록을 불러오거나 정확한 ID를 직접 입력할 수 있습니다.

**모델을 저장하는 것과 활성화하는 것은 다릅니다.** 저장한 모델을 테스트하고 “设为默认并保存” 또는 기본·작업별 할당을 저장해 사용하세요. 작업별로 지정한 모델은 유지되므로 모델 카드의 실제 사용 범위를 확인하세요. 서비스 주소나 프로토콜을 바꾸면 새 서비스에 맞는 키를 입력해야 합니다.

호환 모델의 온라인 조사에는 **联网搜索 · Tavily**에 본인 키를 저장하고 테스트하세요. 원문 추출만 한다면 필요하지 않습니다. 고급 설정에서 회사·직무·리스크에 다른 모델을 할당할 수 있습니다. 선택한 경로가 실패하면 오류를 알리고 다른 유료 서비스로 임의 전환하지 않습니다.

### 로컬 Ollama

Windows에서는 직접 Ollama를 설치·실행하고 PC에 맞는 로컬 모델을 받아 두세요. “Ollama 本机模型”의 기본 주소는 `http://127.0.0.1:11434/v1`이며 API 키가 필요하지 않습니다. 앱은 로컬 루프백 서비스에만 연결하며 Ollama나 모델을 대신 설치하지 않습니다. [Ollama 호환성 문서](https://docs.ollama.com/api/openai-compatibility)도 참고할 수 있습니다.

**Android의 `localhost`, `127.0.0.1`, `::1`은 PC가 아니라 휴대전화 자신을 뜻합니다.** 이 로컬 경로에는 컴퓨터의 LAN 주소를 입력할 수 없으며 APK에 휴대전화용 모델 서버도 포함하지 않습니다. 휴대전화 안에 호환 서비스를 준비하지 않았다면 클라우드 호환 모델이나 AI 없는 인식부터 사용하세요. “설정 저장됨”은 서버가 실행 중이라는 뜻이 아닙니다.

로컬 추론을 원하면 실제로 내려받은 로컬 모델을 선택하세요. 로컬 서비스가 중계하는 클라우드 모델은 여전히 클라우드 서비스입니다. 온라인 조사는 공개 페이지와 Tavily에 접속하며 검색 사용량이 발생할 수 있습니다.

### 기존 Bailian·DeepSeek 설정

“原有官方提供商”는 동일한 설치 ID 안의 기존 설정을 유지하지만, 기기 간 키 이전이나 실제 덮어쓰기 설치 검증을 보장하지는 않습니다. 회사 종합 조사는 Bailian(百炼) 웹 조사를 우선하고 사용할 수 없을 때 **DeepSeek 비웹 분석**으로 전환하는 경로입니다. 이 비웹 결과를 최신 사실이나 출처가 있는 리스크 조사로 취급하지 마세요.

직무 온라인 보완과 회사 리스크 조사에서는 **이 버전의 내장 공식 경로가 `/responses`의 `deepseek-v4-pro`만 허용**하며 Bailian으로 전환하지 않습니다. 기본 `deepseek-v4-flash`는 이 경로에서 지원하지 않는다고 알리고 멈추며 Pro로 자동 변경하지 않습니다. 사용하려면 기존 DeepSeek 설정에서 직접 Pro를 선택하고 저장·테스트한 뒤 직무·리스크가 기존 경로를 쓰는지도 확인하세요. 이는 앱 내부 제한에 대한 설명이며 제공자의 모든 최신 기능을 실측했다는 뜻이 아닙니다.

원문 추출은 검색하지 않으므로 기존 경로에서 설정된 DeepSeek Flash 또는 Pro를 쓸 수 있지만 Bailian만으로는 불가능합니다. 다른 방법은 사용자 정의 호환 모델＋Tavily입니다. DeepSeek를 사용자 정의 모델로 추가해도 Tavily 경로를 쓰며 기존 제공자 키나 내장 검색을 상속하지 않습니다. 공식 Responses 요청 하나가 서버에서 여러 번 검색할 수 있으므로 한 번 클릭을 고정 요금 단위로 생각하지 마세요. [DeepSeek Responses 문서](https://api-docs.deepseek.com/api/create-response/)

**이전 모델 ID는 바뀔 수 있습니다.** 2.6.0은 기존 설정을 위해 `deepseek-v4-flash` 선택지를 유지하지만 2026-10-23 기준 공식 Responses 문서에는 Flash가 `deepseek-flash`로 나옵니다. 이번 릴리스에서 기존 ID가 여전히 사용 가능한지는 실제 계정으로 검증하지 않았습니다. “모델 없음/사용 불가” 오류가 나면 제공자의 현재 문서를 확인하고 유효한 ID로 호환 모델 설정을 추가·테스트하세요. 이 호환 경로의 온라인 조사에는 여전히 Tavily가 필요합니다. 앱은 모델이나 요금 단계를 자동 변경하지 않습니다. [DeepSeek 현재 API 문서](https://api-docs.deepseek.com/api/create-response/)

Android에도 이 경로들을 구현했습니다. 취소나 모델·검색 시간 초과가 발생하면 멈추며 다른 제공자를 추가 호출하지 않습니다. 구현 완료와 실제 기기·서비스 검증 완료는 다릅니다.

## 4. 검토하고 직접 저장하세요

온라인 보완은 기본 지원 기록을 먼저 만든 뒤 실행합니다. 자동 조사가 꺼져 있다면 상세 화면에서 “开始联网补全”을 누르세요. 회사·직무·도시, 근거, 출처를 확인하세요. 근거가 있는 빈 항목만 초안에 미리 채울 수 있으며, 기존 값과 충돌하는 제안은 기본 선택하지 않습니다. 회사 공통 정보 변경은 같은 회사의 다른 직무에도 영향을 줍니다.

선택한 제안을 **加入可编辑草稿**(편집 가능한 초안에 추가)한 뒤 **保存全部更改**(모든 변경 저장)를 눌러야 정식 기록에 반영됩니다. 제안 패널을 닫는 것은 저장이나 취소가 아닙니다. AI가 지원 단계, 우선순위, 연락처, 다음 할 일, 알림, 결과, 개인 메모를 판단해 변경하지 않습니다.

페이지를 읽을 수 없다면 **粘贴招聘原文**(채용 원문 붙여넣기)을 사용하세요.

1. 같은 회사·같은 직무의 글을 **50,000자 이내**로 붙여 넣습니다. 이름, 전화, 이메일, 이력서 내용 등 개인정보는 먼저 지우세요.
2. 실제 직무 모델과 개인정보·요금 안내를 확인한 뒤 실행합니다. 저장한 직무 모델만 호출하며 Tavily, 글 속 링크 열기, 검색, 다른 제공자 전환은 하지 않습니다.
3. 모든 제안은 **선택하지 않은 상태**로 시작합니다. 원문 근거를 확인한 뒤 선택해 초안에 추가하고 마지막으로 직접 저장합니다.

결과에는 “사용자가 제공한 채용 원문, 온라인 미검증”이라고 표시합니다. 원문 근거가 있는 직무·보상 항목만 제안하며 회사 공통 정보나 리스크 평가는 만들지 않습니다. 전체 원문은 현재 창의 메모리에만 있지만 **채택한 항목과 제한된 근거 발췌문은 초안·기록·JSON 백업에 남을 수 있습니다**.

## 5. 저장된 설정 점검과 문제 해결

**AI 一键检查**는 저장된 직무 보완 경로를 점검하며 모든 작업·제공자를 일괄 인증하지 않습니다. 모델과 검색 설정을 먼저 저장하세요. 누락 설정은 외부 요청 없이 로컬에서 확인하고, 설정이 갖춰지면 요금에 동의한 뒤 온라인 점검을 실행합니다. 고정 테스트 문구로 모델 최대 1회, 해당 검색 최대 1회를 순서대로 확인합니다. 지원 기록은 사용하지 않으며 실패하면 자동 재시도나 전환 없이 중단합니다.

| 문제 | 확인할 사항 |
| --- | --- |
| 저장했는데 사용하지 않음 | 기본·작업별 할당. 저장만으로 활성화되지 않음 |
| 모델은 성공하고 검색은 실패 | Tavily 키·제공량 또는 기존 경로의 검색 기능 |
| DeepSeek Flash로 원문은 추출되지만 검색은 안 됨 | 내장 직무·리스크 경로는 Pro를 직접 선택하거나 호환 모델＋Tavily 사용. 모델을 자동 업그레이드하지 않음 |
| Android에서 PC의 Ollama에 연결 안 됨 | 휴대전화 루프백은 PC가 아니며 이 경로는 LAN 주소를 허용하지 않음. 클라우드 모델이나 AI 없는 인식 이용 |
| 인증·호출 제한·잔액 오류 | 해당 서비스의 키, 모델 권한, 한도, 요금 설정 |
| 출처 부족·페이지 접근 불가 | 정확한 회사·도시·공개 링크 또는 원문 붙여넣기 |
| 출력 형식 오류 | 해당 서비스·모델의 필수 구조화 형식 지원 여부 |

중단해도 제공자가 이미 처리한 부분의 요금은 취소할 수 없습니다. 상세를 닫거나 다른 기록으로 이동하면 실행 중인 요청을 취소하며, 같은 상세의 탭 이동은 취소하지 않습니다. Android는 앱이 전면에서 벗어나면 실행 중·대기 중인 AI 네트워크 작업도 취소합니다. 결과를 기다릴 때 앱을 전면에 두고 백그라운드 완료를 기대하지 마세요.

Windows는 Electron 보안 저장소, Android는 Android Keystore로 키 설정을 암호화합니다. 모델·검색 키는 지원 데이터 IndexedDB와 JSON 백업에 포함하지 않으므로 새 기기에서는 직접 설정해야 합니다. 온라인 조사는 필요한 회사·직무 식별 정보와 안전하게 가져온 공개 글만 사용하며 연락처, 개인 메모, 면접 기록, 첨부 내용은 보내지 않습니다. 클라우드 원문 추출은 직접 붙여 넣은 글을 전송하므로 민감한 내용은 미리 지우고 조사용 이름·URL에도 넣지 마세요. 일반 기록·초안·백업은 암호화 금고가 아닙니다.

모의 AI 응답으로 자동 검증했지만 모든 제공자에서 실제 유료 인증 정보로 수행하는 전체 실측은 완료하지 않았습니다. Android의 AI, 시스템 키 저장소, 전면·백그라운드 전환, 서비스 연결도 실제 휴대전화에서는 미검증입니다. 네이티브 구현만으로 모든 휴대전화·모델의 성공을 보장하지 않습니다. 실제 연결, 출력 품질, 남은 사용량은 직접 확인하세요. AI 실패는 로컬 기록 기능에 영향을 주지 않습니다.
