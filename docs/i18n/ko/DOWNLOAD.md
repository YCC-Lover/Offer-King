## 사용 조건과 첫 실행

- Windows 10 / 11, x64. macOS·Linux·모바일 설치 파일은 없습니다.
- 최소 창 크기는 1100 × 700이며, 설정에서 글자 크기를 90%~125%로 조절할 수 있습니다.
- 로컬 지원 관리에는 앱 계정, AI 계정, 인터넷 연결이 필요하지 않습니다. 선택적인 AI 기능은 본인 설정을 사용하며 요금이 발생할 수 있습니다.
- 처음에는 빈 기록에서 시작합니다. 개인 지원 기록이나 공유 API 키가 포함되지 않습니다.

설치 후 사이드바 또는 설정 및 백업 → 화면 및 가독성에서 언어를 고르고 지원 추가로 기록을 만드세요. 전환은 즉시 적용되고 입력 중인 내용을 지우지 않습니다. 회사명·직무명·메모·직접 정한 단계 이름은 원문을 유지합니다. [자세한 사용법(중국어)](../../QUICKSTART.md)

### 2.4.0의 로컬 도구

- **붙여 넣어 빠르게 입력:** 지원 추가의 오프라인 인식 미리 보기에서 원문 근거를 확인하고 선택한 빈 항목만 채웁니다. 기존 입력은 덮어쓰지 않으며 전체 원문은 현재 창의 메모리에만 남고 복구 초안·백업에는 포함되지 않습니다. AI 설정·네트워크 요청·AI 요금이 없습니다.
- **실수령 급여:** 중국 본토 거주자 개인이 1월부터 같은 직장에서 고정 월급을 12개월 받는 CNY 급여의 개인 부담금·소득세를 추정합니다. 어떤 도시든 실제 기준액·비율을 직접 입력할 수 있고 베이징 참고 템플릿은 직접 적용해야 사용됩니다. 원래 채용 기록이나 도시 예산은 바꾸지 않고 외화를 환산하지 않으며 세무 자문이 아닙니다. 계산은 오프라인이며 AI 요금이 없습니다.

## 파일 확인하기

설치 파일이 있는 폴더에서 PowerShell을 열고 실행하세요.

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Offer-King-Setup-2.4.0.exe'
```

파일 크기는 **111,979,180**바이트, SHA-256은 다음과 같아야 합니다.

```text
0670A784B88C53B51C959350012A3894428F5E561BB74D27DC8820200191604D
```

해시 일치는 공개한 파일과 동일하다는 뜻이며 전자 서명이나 안전 인증은 아닙니다. 다른 버전은 해당 릴리스의 값을 확인하세요.

서명되지 않은 파일이므로 “알 수 없는 게시자”나 SmartScreen 안내가 나올 수 있습니다. 다운로드 출처를 확인하고 Windows 보안 안내를 따르세요. Defender나 SmartScreen 등 보호 기능을 끄지 마세요. 파일을 확인할 수 없거나 차단이 계속되면 중단한 뒤 [문제를 신고](https://github.com/YCC-Lover/Offer-King/issues/new?template=bug_report.yml)해 주세요.

## 기존 버전을 업데이트한다면

1. 기존 앱의 “设置与备份”에서 JSON을 직접 내보내 보관하세요. 첨부 원본 파일은 별도로 보관합니다.
2. 앱을 종료하고 기존 설치 위치를 유지하세요. 업데이트 준비를 위해 앱 데이터를 지우지 마세요.
3. 후보 버전의 검증 범위를 확인한 뒤 설치 파일을 실행하세요. 실행 후 회사, 지원 기록, AI 설정 상태를 확인하고 업데이트 전 백업을 계속 보관하세요.
4. 이상이 있으면 현재 상태를 유지하고 신고하세요. 확인하지 않은 기록을 지우거나 백업으로 덮어쓰지 마세요.

기존 설치 식별 정보와 데이터 위치를 유지하도록 설계했습니다. 검증 범위는 릴리스 노트를 확인하세요. 자동 점검은 실제 설치 파일의 덮어쓰기 검증을 대신하지는 않습니다. JSON에는 API 키, 저장하지 않은 초안, 첨부 원본이 들어 있지 않습니다. 다른 PC로 옮기면 첨부 원본을 따로 이동하고 본인 AI 키를 다시 설정해야 합니다.

**자동 업데이트나 앱 내 새 버전 푸시는 없습니다.** 릴리스 페이지를 직접 확인하고 안내를 읽은 뒤 백업하고 업데이트를 수동으로 받으세요. GitHub의 Latest는 다른 버전을 가리킬 수 있습니다. 2.4.0 후보 버전은 위의 고정 링크로 받으세요. 친구에게는 이 페이지와 설치 파일·안내만 공유하고 개인 데이터 폴더·백업·키는 공유하지 마세요.
