**Android 2.6.1 / Windows 2.6.0 の少人数向け試用候補版（Pre-release）**に対応した説明です。2.6.1 は Android のみの更新で、AI 設定・経路は変更しません。試用期限や追加の機能ロックはありません。サイドバーや表示設定から簡体字中国語・英語・日本語・韓国語へすぐ切り替えられ、入力途中の内容も保持します。[ダウンロードと確認](DOWNLOAD.md) · [Android 2.6.1 リリース](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.6.1) · [Windows 2.6.0 リリース](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.6.0)

以前の画像とも照合できるよう、操作名には中国語を併記しています。表示言語の変更で記録を翻訳したり、AI の提供元・キー・モデル・検索経路・料金への同意を変更したりはしません。

応募、予定、オファー比較、バックアップには AI は不要です。AI は自分のアカウントとキーで使う任意機能で、利用枠の消費や料金が発生する場合があります。**共有キーや無制限の無料サービスは含まれません。**

### 最初に利用端末を確認する

| 端末 | 試用ファイルと検証範囲 | AI 設定の違い |
| --- | --- | --- |
| Windows 10/11 x64 | `Offer-King-Setup-2.6.0.exe`。正式なコード署名はありません。パッケージの起動・画面検証は、新規・上書き・アンインストールの実機検証ではありません | 互換クラウドモデル、OpenRouter＋Tavily、従来の百炼／DeepSeek、ローカル Ollama を実装。キーは Electron の安全なストレージで暗号化 |
| Android | `Offer-King-2.6.1-android-trial.apk`。2.6.0 と同じ Debug 開発署名。実機の初回・上書きインストールと暗号化キーの継続利用は未検証 | モデル接続・一覧、原文抽出、企業・求人・リスク調査をネイティブ実装。キーは Android Keystore で暗号化。Ollama のループバックは PC ではなくスマートフォン自身 |
| macOS / iPhone / iPad | 今回、インストール用パッケージは提供しません | ソースや模擬テストを、検証済みの Apple 向けビルドと考えないでください |

初回インストールは空のデータで始まります。Android 2.6.1 は従来のアプリ ID、保存元、署名、AI ストレージを維持する設計ですが、実機での保持は未検証です。先に編集を保存し、アプリの保存領域外に JSON を書き出してください。**アンインストール・データ消去・AI 設定リセットをせず、既存アプリへ更新**し、起動後に記録と AI 設定状態を確認します。署名競合時は中止して報告してください。JSON に API キーと添付原本は含まれず、削除後のキーは復元できません。クラウド同期や作者の記録・キーは含みません。該当版の `START-HERE.md`、`SHA256SUMS.txt`、`TEST-RESULTS.json` に手順と検証範囲を記載しています。

## AI を設定せずに始める

**2.6.0 の操作改善に AI は不要です。** クイック検索、ボード／一覧、組み合わせフィルター、保存ビュー、次のアクションの簡単編集は端末内で動きます。従来の AI 設定と自動調査の選択は維持し、新規ユーザーの自動調査は初期状態で無効です。次のアクションの編集から調査は開始しません。[新機能（中国語）](../../RELEASE-2.6.0.md)

**応募を追加 → 求人情報を貼り付け**では、明記された企業名・職種・都市・リンク・給与などを端末内で抽出し、プレビューで空欄への入力を選べます。既存の入力や再利用する企業の共有情報は変えず、不明確な情報は推測しません。通貨不明の金額は初期状態で未選択です。全文は画面のメモリにだけ保持し、復元用下書き・バックアップには保存しません。以下の AI 原文抽出とは別機能で、キー・通信・AI 料金は不要です。

**手取り給与**もモデルを使わず端末内で計算します。中国本土の居住者個人が 1 月から同一勤務先で固定月給を 12 か月受け取る CNY 給与を対象とします。都市名と実際の基数・料率を入力でき、検証済みのテンプレートは現在北京のみで、明示的に適用する必要があります。求人の給与や都市予算には書き戻さず、外貨も換算しません。給与明細・税務助言ではなく概算であり、AI 料金は発生しません。

## 1. 何をしたいかで選ぶ

| 用途 | 必要な設定 | Web 検索 |
| --- | --- | --- |
| 応募作成前の明確な項目の抽出、または手取り試算 | 不要。端末内ツール | AI・ネット通信なし |
| AI で貼り付けた求人原文からさらに項目を抽出 | 対応する求人用モデル、または準備済みのローカル Ollama モデル | なし。Tavily は不要 |
| 企業・求人の公開情報を調査 | 対応モデル＋自分の Tavily キー、または従来の提供元の経路 | あり。出典を確認 |
| 端末内の記録、予定、比較、バックアップ | なし | AI 呼び出しなし |

原文抽出は**インターネットでの裏付け確認ではありません**。普通のモデルにキーを入力しても検索機能が自動で付くわけではなく、接続成功だけで検索や構造化抽出が成功するとは限りません。企業サイトのアイコン取得と更新確認は別の通信機能なので、端末内の抽出を使うことがアプリ全体の通信停止を意味するわけでもありません。

## 2. 無料スタート設定

1. **设置与备份 → AI 调研 → 免费 AI 起步**（設定とバックアップ → AI 調査 → 無料 AI スタート）を開きます。
2. [OpenRouter](https://openrouter.ai/settings/keys) で自分のキーを作り、「OpenRouter 免费模型 API Key」に入力します。プリセットは `https://openrouter.ai/api/v1` の `openrouter/free` を使います。
3. [Tavily](https://app.tavily.com/home) で自分の検索キーを取得し、「免费起步 Tavily API Key」に入力します。無料枠内に収めたい場合は、両サービスの現在の枠と課金設定を確認してください。
4. **保存并启用免费配置**（無料設定を保存して有効化）を押します。企業・求人・リスクの 3 タスクを明示的にこの設定へ切り替えます。保存だけで調査は開始しません。
5. モデルと検索を個別にテストするか、料金の説明を確認してワンクリックチェックを行います。テストも利用枠を消費する場合があります。

無料プリセットではゼロ価格の提供元を指定する制限も付け、有料モデルへ無断で切り替えません。ただしモデルの可用性や枠は変わり、一定量の利用や永久無料は保証しません。Tavily はチャットモデルではなく検索サービスで、モデルとは別の利用枠・料金があります。この経路の新しい調査は 1 回につき basic 検索を最大 1 回行い、自動で検索深度を上げません。有効期限内の候補を選ぶ場合は最初の証拠を再利用します。サービス側の課金設定は自分で管理してください。[OpenRouter の無料ルーター説明](https://openrouter.ai/docs/guides/routing/routers/free-router)・[Tavily の利用枠説明](https://docs.tavily.com/documentation/api-credits)を確認できます。

「创建岗位后自动调研」（応募作成後に自動調査）は**初期状態で無効**です。必要なら有効にして「保存自动调研偏好」で保存します。新規応募の作成成功後に 1 回呼び出し、入力中や既存の応募を開いたときには自動実行しません。

## 3. 自分のモデルを使う

**我的模型配置 → 新增模型配置**（自分のモデル設定 → 追加）で、分かりやすい名前、プロトコル、ベース URL、正確なモデル ID、対応する API キーを入力します。OpenAI 互換の Chat Completions、Responses、ローカル Ollama に対応しますが、アプリで必要な構造化出力をモデルとサービスがサポートする必要があります。チャット Web サイトの有料会員資格が API 利用枠を含むとは限りません。

クラウドの接続先は公開 HTTPS アドレスを指定し、保存前に認識されたベース URL を確認してください。「读取模型列表」で一覧を読み込むか、正確な ID を手入力できます。

**モデルを保存するだけでは有効になりません。** 保存済みモデルをテストし、「设为默认并保存」などで既定またはタスクの割り当てを保存します。タスクごとの個別指定は残るため、モデルカードの使用範囲を確認してください。接続先や方式を変えたら、新サービス用のキーも入力します。

互換モデルでのオンライン調査には **联网搜索 · Tavily** で自分のキーを保存・テストします。原文抽出だけなら不要です。詳細設定では企業、求人、リスクに別々のモデルを指定できます。選択した経路が失敗したら通知し、別の有料サービスへ無断で切り替えません。

### ローカル Ollama

Windows では Ollama を自分でインストール・起動し、PC に合うローカルモデルを取得してください。「Ollama 本机模型」の既定値は `http://127.0.0.1:11434/v1` で、API キーは不要です。アプリはローカルのループバックアドレスだけに接続し、Ollama やモデルを自動インストールしません。[Ollama の互換性ドキュメント](https://docs.ollama.com/api/openai-compatibility)も参照できます。

**Android の `localhost`、`127.0.0.1`、`::1` は PC ではなくスマートフォン自身です。** このローカル経路に PC の LAN アドレスは指定できず、APK にスマートフォン用のモデルサーバーも含みません。端末内の対応サービスを準備していない場合は、互換クラウドモデルか AI 不要の抽出を使ってください。「保存済み・設定済み」はサーバーの稼働確認ではありません。

端末内で推論したい場合はダウンロード済みのローカルモデルを選びます。ローカルサービス経由でもクラウドモデルならクラウド利用です。オンライン調査では公開ページと Tavily への通信・検索枠の消費が発生します。

### 従来の百炼／DeepSeek 設定

「原有官方提供商」で同じインストール ID の従来設定を保持しますが、別端末へのキー移行や上書きインストールの実機検証を保証するものではありません。企業の総合調査は百炼（Bailian）の Web 調査を優先し、利用できない場合に **DeepSeek の非 Web 分析**へ切り替える経路です。非 Web の結論を最新情報や出典付きリスク調査と扱わないでください。

求人のオンライン補完と企業リスク調査では、**この版の組み込み公式経路は `/responses` の `deepseek-v4-pro` だけを許可**し、百炼には切り替えません。既定の `deepseek-v4-flash` はこの経路では非対応として停止し、Pro へ自動変更しません。利用するには従来の DeepSeek 設定で自分で Pro を選択し、保存・テストして、求人／リスクの経路も確認します。これはアプリの制限の説明で、提供元の全機能を実測したという意味ではありません。

原文抽出は検索しないため、従来経路では設定済みの DeepSeek Flash または Pro を使えますが、百炼だけでは実行できません。別の選択肢はカスタム互換モデル＋Tavily です。DeepSeek をカスタムモデルとして追加した場合も Tavily 経路になり、従来設定のキーや内蔵検索を引き継ぎません。公式 Responses の 1 リクエスト内で複数回検索される場合があり、1 クリックを固定の料金単位と考えないでください。[DeepSeek Responses の説明](https://api-docs.deepseek.com/api/create-response/)

**旧モデル ID は変わる場合があります。** 2.6.0 は既存設定との互換性のため `deepseek-v4-flash` の選択肢を保持しますが、2026-10-23 時点の公式 Responses 文書では Flash を `deepseek-flash` と記載しています。本版では旧 ID が引き続き使えるかを実際のアカウントで検証していません。「モデルが存在しない／利用できない」と表示されたら、提供元の現行文書を確認し、有効な ID で互換モデル設定を追加してテストしてください。この互換経路のオンライン調査には引き続き Tavily が必要です。アプリはモデルや料金プランを自動変更しません。[DeepSeek の現行 API 文書](https://api-docs.deepseek.com/api/create-response/)

Android にもこれらを実装しています。中止やモデル／検索のタイムアウト時は停止し、次の提供元を呼び出しません。実装済みであることと、実機・実サービスでの受け入れ検証済みであることは別です。

## 4. 確認して、明示的に保存する

オンライン補完では先に基本の応募を作成します。自動調査が無効なら、詳細の「开始联网补全」から実行します。企業、職種、都市、根拠、出典を確認してください。根拠のある空欄だけが下書きに事前入力され、既存値と競合する提案は初期状態で選択されません。企業共有情報の変更は、その企業の他の応募にも影響します。

必要な提案を **加入可编辑草稿**（編集可能な下書きへ追加）し、**保存全部更改**（すべての変更を保存）で正式に記録します。提案パネルを閉じても、下書きの保存や取り消しにはなりません。ステージ、優先度、連絡先、次の行動、通知、選考結果、個人メモは AI が判断して変更しません。

読めないページの紹介文は **粘贴招聘原文**（求人原文を貼り付け）で抽出できます。

1. 同じ企業・同じ職種の文章を **50,000 文字以内**で貼り付けます。氏名、電話、メール、履歴書、その他の私的情報を先に取り除いてください。
2. 実際の求人用モデルとプライバシー・料金を確認して実行します。保存済み求人モデルのみを呼び出し、Tavily、リンクの読み込み、検索、別提供元への切替は行いません。
3. 提案は**すべて未選択**から始まります。原文の根拠と照合して選び、下書きへ加え、最後に明示的に保存します。

結果は「ユーザー提供の求人原文・オンライン未検証」と表示します。原文で裏付けられた求人・待遇項目のみを提案し、企業共有情報やリスク評価は生成しません。全文は現在のウィンドウのメモリだけに保持しますが、**採用した項目と一部の根拠引用は、下書き・記録・JSON バックアップに残る場合があります**。

## 5. 保存済み設定のチェックと対処

**AI 一键检查** は保存済みの求人補完経路のチェックであり、すべてのタスクや提供元を一括認証するものではありません。先にモデル・検索設定を保存してください。不足設定は通信せず端末内で確認でき、設定が揃ったら料金の同意後にオンラインチェックを実行します。固定のテスト文を使い、モデル 1 回・対応検索 1 回を最大として順番に確認します。応募記録は使わず、失敗後に自動再試行や切替はしません。

| 症状 | 確認すること |
| --- | --- |
| 保存したのに使われない | 既定とタスクの割り当て。保存だけでは有効にならない |
| モデルは成功、検索は失敗 | Tavily のキーと枠、または従来経路の検索機能 |
| DeepSeek Flash で原文は抽出できるが検索できない | 組み込み求人／リスク経路は Pro を明示的に選ぶか、互換モデル＋Tavily へ。自動でモデルは変更しません |
| Android から PC の Ollama に接続できない | スマートフォンのループバックは PC ではなく、この経路は LAN アドレス不可。クラウドモデルか AI 不要の抽出を利用 |
| 認証・回数制限・残高のエラー | 該当サービスのキー、モデル権限、枠、課金設定 |
| 出典不足・ページを読めない | 企業名、都市、公開リンク。必要なら原文を貼り付け |
| 出力形式エラー | そのサービスとモデルが必要な形式に対応しているか |

中止しても、提供元が処理済みの部分の料金は取り消せません。詳細を閉じる、または別の記録へ移ると実行中リクエストを中止します。同じ詳細のタブ移動では中止しません。Android はフォアグラウンドを離れると、実行中・待機中の AI 通信も中止します。結果を待つ間はアプリを前面に保ち、バックグラウンドでの完了を期待しないでください。

Windows は Electron の安全なストレージ、Android は Android Keystore を使ってキー設定を暗号化します。モデル・検索キーは求職用 IndexedDB や JSON バックアップには含めないため、別端末では自分で設定します。オンライン調査は必要な企業・求人の識別項目と安全に取得した公開文だけを使い、連絡先、個人メモ、面接履歴、添付内容は送りません。クラウドでの原文抽出には自分で貼り付けた文章が送られるため機密情報を除き、調査用の名前・URL にも私的情報を入れないでください。通常の記録・下書き・バックアップは暗号化保管庫ではありません。

模擬 AI 応答による自動検証は行っていますが、すべての提供元で実際の有料認証情報を使った一連の実測は未完了です。Android の AI、システムのキー保存、前面・背面の切替、サービス接続も実際のスマートフォンでは未検証です。ネイティブ実装済みであっても全端末・全モデルでの動作を保証しません。接続、出力品質、残りの枠は各自で確認してください。AI が失敗しても端末内の記録機能は使えます。

### 更新の通知と、自動インストールは別です
