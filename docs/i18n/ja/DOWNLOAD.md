## 動作条件と使い始め方

- Windows 10 / 11、x64。macOS、Linux、スマートフォン向けのインストーラーはありません。
- 最小ウィンドウは 1100 × 700。設定で文字サイズを 90%～125% に変更できます。
- 端末内の応募管理にはアプリ用アカウント、AI アカウント、インターネット接続は不要です。任意の AI 機能は自分で設定し、料金が発生する場合があります。
- 初回は空の記録から始まります。個人の応募記録や共有 API キーは同梱していません。

インストール後はサイドバー、または「設定・バックアップ → 表示・読みやすさ」で言語を選び、「応募を追加」で記録を作成します。切替はすぐに反映し、入力途中の内容は消しません。企業名・職種名・メモ・独自のステージ名は元のままです。[操作ガイド（中国語）](../../QUICKSTART.md)

## ファイルを確認する

インストーラーのあるフォルダーで PowerShell を開き、実行します。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\Offer-King-Setup-2.3.0.exe'
```

ファイルサイズは **111,824,372** バイト、SHA-256 は次の値です。

```text
E3F0793EE439D6975C45CA566BBE07D077C62416F5753329C73435C2DC037463
```

ハッシュ一致は公開ファイルとの同一性を確認するもので、電子署名や安全性の認証ではありません。別バージョンでは該当リリースの値を使ってください。

未署名のため「不明な発行元」や SmartScreen が表示される場合があります。取得元を確認し、Windows のセキュリティ案内に従ってください。Defender や SmartScreen などの保護は無効にしないでください。確認できない場合やブロックが続く場合は作業を止め、[問題を報告](https://github.com/YCC-Lover/Offer-King/issues/new?template=bug_report.yml)してください。

## 旧バージョンから更新する場合

1. 旧版の「设置与备份」から JSON を手動で書き出し、大切に保管します。添付ファイルの原本も別途保管してください。
2. アプリを終了し、既存のインストール先を維持します。更新準備のためにアプリデータを消去しないでください。
3. 候補版の検証範囲を理解したうえでインストーラーを実行します。起動後は企業、応募、AI 設定の状態を確認し、更新前のバックアップを残してください。
4. 異常があれば現状を保持して報告し、未確認の記録を削除したりバックアップで上書きしたりしないでください。

従来のインストール識別情報とデータ保存先を維持する設計です。検証範囲はリリースノートを確認してください。自動テストは実インストーラーの上書き検証の代わりにはなりません。JSON に API キー、未保存の下書き、添付ファイル本体は含まれません。別の PC では添付原本の移動と自分の AI キーの再設定が必要です。

自動更新はありません。GitHub の Latest は別バージョンを指す場合があります。2.3.0 候補版は、このページの固定リンクを使ってください。友人にはこのページとインストーラー、ガイドを共有し、個人データやキーは渡さないでください。
