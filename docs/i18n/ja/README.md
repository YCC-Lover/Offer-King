# Offer King

### 応募の進み具合を整理して、納得できるオファー選びへ。

応募のフォロー、待遇の比較、転居後の生活設計まで。端末内保存を基本とした、個人の就職・転職活動のためのアプリです。

## 日々の応募管理から、最後の比較まで

複数の応募先を管理したい方、オファーを比較したい方、転居も含めて考えたい方へ。

- **応募を見失わない。** ステージ別ボード、面接の履歴、次のアクションと日時を整理。同じ企業の複数職種も独立して管理できます。

- **入力を減らす。** 求人原文を貼り付け、端末内で抽出した根拠を確認して、選んだ空欄だけに入力。既存の入力や再利用する企業の共有情報は上書きせず、不明な情報は推測しません。

- **大事な条件を比べる。** 通常年の想定年収と初年度総額を分けて表示。2 件のオファーを自分の優先順位で比較できます。

- **手取りを試算する。** 中国本土の CNY 給与について、社会保険・住宅積立金・所得税と 12 か月の手取りを確認。元の求人の給与情報は変更しません。

- **転居後の暮らしを考える。** 家賃、通勤費、生活費を自分で入力し、貯蓄の目安を比較。リアルタイムの地域相場ではなく、自分の条件に基づく予算です。

- **判断の根拠を残す。** 企業情報、出典付きリスク調査、個人の企業トップ 3 を確認。スコアは意思決定の補助であり、客観的な企業格付けではありません。

## まずは 3 ステップ

1. **ダウンロードして確認。** 上の Windows 版または Android 試用版を選び、[ダウンロードガイド](DOWNLOAD.md)に従ってください。公開ファイルの取得に GitHub アカウントや開発ツールは不要です。

2. **最初の応募を作成。** UI 言語を選び、企業名・職種を入力するか、求人原文を貼り付けてオフラインのプレビューを確認。都市とステージを確認し、必要に応じて既存の企業を再利用します。次にすることが決まったら日時も残しましょう。

3. **保存してバックアップ。** 必要な情報を少しずつ加え、変更は明示的に保存し、JSON を定期的に書き出してください。添付原本は別途保管します。AI 設定は後からでかまいません。

言語はすぐに切り替わり、この端末に記憶します。**企業名・職種名・メモ・独自のステージ名は翻訳しません。** 編集中の入力も保持します。言語設定は求職データのバックアップには含めません。

## Android 2.6.1 試用版の変更点

- **アプリ内で次の試用版を確認。** 「ヘルプ・アプリ情報 → アプリの更新」で手動確認でき、自動確認が有効なら前面での使用中に最大 24 時間に 1 回確認します。「候補版を含める」が必要で、無視した版の設定も尊重します。案内から公式リリースページを開き、取得とインストールは自分で行います。
- **2.6.0 以前からは最初の 1 回だけ手動更新。** 旧 Android 試用版は試用 APK のファイル名に一致しないため、2.6.1 を既存アプリに上書きして修正版の確認機能を導入してください。旧 APK に遠隔で機能を追加することはできません。
- **既存の記録・AI 設定を維持する設計。** アプリ ID、保存元、AI ストレージと 2.6.0 の Debug 署名を継続します。先にアプリ外へ JSON を書き出し、添付原本を別途保管してください。アンインストール、データ消去、AI 設定のリセットは不要です。JSON にキーと添付原本は含みません。実機の初回・上書きインストールと暗号化キーの継続利用は未検証であり、署名競合時は中止してください。
- **ダークモードの更新案内を読みやすく。** 文字のコントラストを改善しました。更新確認は AI を呼ばず、記録やキーを送らず、AI 料金は発生しません。AI 設定・呼出経路は変更しません。

## 2.6.0 から引き継ぐ機能

- **記録をすばやく探す。** ヘッダーまたは `Ctrl/Cmd + K` から、ページ・企業・応募を端末内で検索し、キーボードで開けます。
- **ボードと一覧を切り替える。** ステージ・優先度・都市・勤務形態・お気に入り・予定の 6 種類を組み合わせて絞り込み、並べ替え、**最大 12 件の名前付きビュー**を保存できます。一覧は **1 ページ 30 件**。保存するのは表示条件で、記録のコピーや検索語ではありません。
- **次のアクションをその場で編集。** ボード・一覧・予定から内容と日時を変更し、明示的に保存できます。変更は履歴に残り、選考ステージは自動変更しません。
- **日々の作業を見やすく。** コンパクトなホームで予定を優先表示し、詳細の補助項目は必要なときに展開。モバイルの大きい文字、スクロール、固定操作欄も改善しました。

これらの新機能は端末内で動き、AI を呼び出しません。自動調査は引き続き初期状態で無効です。**単体・コンポーネント 1,280 件**、**Node 314 件**（4 件スキップ）、**パッケージ版 Electron 5 シナリオ**、**架空データによる展開済み 2.5.4 → 2.6.0 更新 1 シナリオ**が成功しました。Android はコンパイルとパッケージの静的確認済みですが、ブラウザーのタッチ・画面検証は実機検証ではありません。Windows の実インストールと Android 実機の受け入れ検証は未完了です。

## AI は必要なときに

**まずは AI なしで始められます。** 目的に合わせて選んでください。

1. **オフライン・設定不要：** 端末内の記録、クイック入力、手取り試算には、モデル・キー・ネット接続・AI 料金が不要です。

2. **モデルだけで原文抽出：** 手元の求人原文を、設定済みの対応モデルで分析します。対応環境では準備済みのローカル Ollama も選べます。Web 検索や原文の裏付け確認は行わず、検索キーは不要です。

3. **モデル＋検索で調査：** 対応モデルと必要な検索経路を設定し、公開された企業・求人情報を調べます。OpenRouter＋Tavily のスタート設定にも、**自分のアカウントとキー**が必要です。

**共有 API キーの同梱や、無料クラウド枠の保証はありません。** モデル、検索、接続テストは利用枠を消費したり料金が発生したりする場合があります。可用性と互換性は各サービスに依存します。従来の百炼（Bailian）・DeepSeek 設定や環境別の制約は、[AI 設定ガイド](AI-SETUP.md)をご覧ください。

応募作成後の自動調査は、**初期状態では無効**です。出典と日付を確認し、提案を選んで下書きに反映してから、**明示的に保存**してください。AI の出力は確認済みの事実ではなく、記録を黙って上書きしません。

## よくある質問

<details>
<summary><strong>アカウントも AI も設定せず、オフラインで使えますか？</strong></summary>

はい。端末内の記録、ステージ、履歴、次のアクション、比較、予算、JSON バックアップにアプリのアカウントや AI は不要です。クラウド同期や共同編集はありません。予定はアプリ内の表示であり、終了後も動くシステムアラームではありません。企業アイコンや AI は通信する場合があります。

</details>

<details>
<summary><strong>日本など、中国本土以外の税・手取りも計算できますか？</strong></summary>

できません。中国本土の居住者個人が、1 月から同じ勤務先で固定月給を 12 か月受け取る CNY 給与の試算です。都市に応じた実際の算定基数・料率を自分で指定し、北京の参考テンプレートも明示的に選んだ場合だけ適用します。国際的な給与計算や税務助言ではなく、外貨も自動換算しません。結果は求人や都市予算に書き戻しません。

</details>

<details>
<summary><strong>何をバックアップし、友人には何を共有すればよいですか？</strong></summary>

共有するのはインストーラーやプロジェクトのリンクにし、個人のデータフォルダーやバックアップは渡さないでください。インストーラーに作者の記録やキーは含まれず、各自の空の記録から始まります。キーは各 OS のセキュアストレージで保護し、求職データの JSON には含めません。ただし記録・復元用下書き・バックアップ自体は、**暗号化された保管庫ではありません**。

JSON に**添付ファイルの原本は入りません**。Windows はローカルパス、Android は端末固有の文書アクセス権を使い、その権限はバックアップと一緒に別端末へ移りません。原本は別途保管してください。

クラウド抽出では、貼り付けた文章が選択したモデルへ送信されます。全文はメモリ内だけに保持しますが、採用した項目と一部の根拠引用は下書き・記録・バックアップに残る場合があります。送信前に個人情報を除いてください。[プライバシーの詳細（中国語）](../../PRIVACY.md)

</details>

<details>
<summary><strong>更新方法と、対応する OS・言語を教えてください。</strong></summary>

Windows 2.5.4 以降は前面での使用中に手動確認でき、自動確認が有効なら最大 24 時間に 1 回確認します。Windows 2.6.0 を受け取るには**候補版を含める**を有効にし、2.4.0 以前は最初に手動更新してください。**Android 試用版 2.6.0 以前も、最初は手動で 2.6.1 へ更新する必要があります。** 2.6.1 以降は「ヘルプ・アプリ情報 → アプリの更新」で今後の公式試用 APK を確認できます。候補版・自動確認・無視した版の設定は尊重し、**自動取得・インストールはしません**。署名競合時は中止し、データを消して解決しないでください。[バックアップと更新手順](DOWNLOAD.md)

公開試用版は Windows 10 / 11 x64 と Android 7.0 以上で、簡体字中国語・英語・日本語・韓国語の UI に対応します。実機の受け入れ検証は未完了です。macOS・iOS・Linux のインストーラーやポータブル版はありません。最小ウィンドウ 1100 × 700 は Windows のみの条件です。

</details>
