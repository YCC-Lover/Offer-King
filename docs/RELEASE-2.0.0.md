# Offer King 2.0.0 · 早期试用版

投递太多记不住，拿到 Offer 又难选择？Offer King 把投递跟进、薪资分析、双 Offer PK 和城市生活预算放在一起，帮你记录进度，也看清不同机会的差异。让每一份 Offer 都更值得。

## 可以先试试

1. 新增第一条投递，按阶段跟进下一事项。
2. 在“我的 Offer”整理决策截止，在“双 Offer PK”填写自己的权重和偏好。
3. 通过“薪资分析”分清常态年包与首年总包；用“城市生活”记录自己的收入和生活预算。
4. 设置中选择浅色 / 深色主题及 90%–125% 字号，定期导出 JSON 备份。

无需 App 账号，AI 可选，朋友从自己的空数据开始。PK 和预算请明确点击保存；未保存输入暂不支持异常重启恢复。
