## 本版新增

- **四种界面语言：** 简体中文、English、日本語、한국어。侧栏和“设置与备份 → 显示与可读性”均可选择，立即生效，无需重启，本机记住选择。
- **编辑和原文保持：** 语言切换不清除当前输入；公司名、岗位名、备注、人工阶段名和已有调研内容保持原文。默认阶段翻译仅用于显示，不改存储名称。
- **文档语言入口：** GitHub 首页、下载和 AI 配置指南提供四语互链；每种新增语言均有独立说明，可直接按步骤使用。

界面语言只作用于本机显示偏好，不进入求职数据库、JSON 备份或 AI 安全配置。没有因为切换语言而产生 AI 请求，也不会自动翻译用户资料或更换 AI 模型。

## 原有功能与数据兼容

保留全部待办、PK 与城市预算恢复草稿、招聘原文提取和 AI 一键检查等日常功能。仍以明确保存为准；恢复草稿和 AI 预览不会替你自动提交。

`offerflow-db` 保持 version 1，备份保持 `schemaVersion: 1`；保留安装身份、数据位置、附件路径及 AI 配置。旧版公司、岗位和人工阶段名称不因界面翻译而改写；不清空或迁移求职记录，不接触旧 `love-notes-db`。

设计兼容不等于真实安装器验收。旧用户更新前请导出完整 JSON，附件原文件另外保管；不要为升级先删除数据或卸载旧版。JSON 不含 API Key、未提交草稿和附件文件本身。

## AI、费用与隐私

本版不新增 AI 提供商或后台收费调用。AI 可选，**没有内置共享 API Key 或无限免费服务**；朋友应使用自己的模型、搜索账户和密钥。免费额度、可用性和计费由提供商账户决定，连接测试也可能消耗额度。

招聘原文提取不搜索、不打开文字中的网址，标记为“未经联网核实”；云端模型会收到主动提交的文本。完整原文只在窗口内存中保留，已采纳字段和有限证据摘录可进入草稿、记录与备份。结果需自行核实并明确保存。API Key 不进入求职 JSON，附件只保存路径。[AI 配置指南](AI-SETUP.md) · [数据与隐私](PRIVACY.md)
