## 这版有什么变化

- **Windows 新版提醒：** 启动及使用期间可自动检查固定 GitHub 公开发布源，每天最多一次；也可手动检查、忽略某版本或关闭自动检查。只有适配本平台、版本严格更新且渠道允许的资产才显示提醒。不自动下载或安装，不在关闭 App 后常驻。
- **安卓开发试用：** 复用主要本地公司、岗位、看板、决策与备份界面，加入原生 AI 安全配置、附件选择与重新定位、官网图标等适配。本轮实际编译并静态核验 APK，未把源码实现当作手机运行验收。
- **AI 配置与排错：** 保留百炼、DeepSeek、自有兼容模型、可选搜索和招聘原文提取；改善配置状态、取消、来源核对及补全说明。普通模型能连接不代表会搜索，建议仍需用户核对并保存。安卓与 Windows 的环境差异见 AI 指南。
- **试用身份更清楚：** 关于页顶部增加“小范围试用版”，区分 Windows 未正式签名与 Android 开发测试签名，并补齐英、日、韩说明。没有试用到期限制，不人为关闭本地功能。
- **继续保留：** 四语界面、90%–125% 字号、本机招聘文字识别、到手工资试算、全部待办、恢复草稿、公司风险与排行、Offer PK、城市预算和备份。

2.4.0 及更早公开版本没有这些 App 内新版提醒能力，需先手动升级一次。发布这个 Release 不会给旧 App 自动增加功能。安卓 Debug 文件不作为正式自动升级资产推荐；未来更换签名可能不能直接覆盖，需另行备份迁移。

## 第一次使用与 AI

安装成功后无需应用账号，先用虚构公司和岗位试一遍“新增 → 保存 → 关闭重开 → 导出备份”。朋友各自从本机空数据开始，设备之间不自动同步。

不配置 AI 也能使用本地记录和比较。AI 使用自己的密钥，不内置共享 Key；免费起步预设不等于永久免费，搜索、模型和连接测试可能消耗服务商额度。建议先使用不联网的本机规则识别，需要模型理解或联网时再按 [AI 配置指南](AI-SETUP.md)明确保存、测试和启用。

## 已验证与尚未验收

**实际已完成：**

- TypeScript 类型检查、全范围代码规范检查、1214/1214 单元／组件测试通过；定向多语言测试属于其中子集，不重复累计。
- 当前 Windows 生产构建及精确 ASAR／外部资源核对通过；打包程序冒烟 5 项通过、0 失败、1 项按设计跳过。跳过项是只适用于开发 Electron 的启动测试，不计为打包程序通过。
- 当前 Windows 打包程序实际界面 7 项检查通过，包括 125% 字号、滚轮到底、试用说明，以及合成记录、字号关闭重开持久化。请求 1100×700，本机 DPI 取整为 1101×700；不代表物理多屏与全部缩放组合验收。
- 安卓离线 Debug 编译完成；独立工具核验 v2 调试签名、版本、权限、对齐、21 项载荷及对应原生／前端源码。实际包内包含本轮试用说明，不是旧 APK 改名。
- Windows 安装器与主程序系统签名检查均为 NotSigned；安卓仍是 Debug 签名。这些事实不表述为可信发布者认证。

**明确未完成：**

- 干净 Windows 的 NSIS 首装、覆盖安装和卸载；没有在日常账号运行安装器代替独立环境验收。
- Android 真机首装、覆盖、系统附件权限、后台恢复、原生 AI、官网图标和 WebView 运行验收。
- 真实付费模型／搜索的端到端质量与费用验证；测试使用合成数据或模拟响应。
- 所有显卡、DPI、多屏、安卓厂商与系统组合，以及任意第三方模型的兼容性。
- Mac／iOS 的真实编译、签名、公证、安装或分发；没有可下载 Apple 安装包。
