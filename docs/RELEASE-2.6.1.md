## 安卓更新提醒

- 修复官方 `android-trial.apk` 文件名无法被版本检查识别的问题。
- 在“帮助与关于 → 应用更新”手动检查新版，或启用“启动及使用期间自动检查”和“同时接收候选试用版提醒”。保留已有的关闭、忽略偏好，不强制开启。
- 前台启动约五秒后检查，使用期间或返回前台也会按预算检查；自动联网最多每 24 小时一次，手动检查不受该间隔限制。
- 找到适配的更高版本后显示 App 内提醒，可打开该版官方发布页，再自行下载 APK、选择覆盖更新。没有后台推送、自动下载或静默安装。
- 只接受固定官方仓库、完整版本及允许的 APK 文件名，关闭候选渠道后不会推荐 trial 包；检查版本不调用 AI、不发送求职记录或 API Key。
- 更新信息采用主题配色，修复深色模式浅底浅字，并检查小屏、大字号与滚动查看。

**安卓 2.6.0 及更早试用用户必须先手动安装 2.6.1 一次。** 旧 APK 内的匹配逻辑不会因 GitHub 发布而远程改变。装好 2.6.1 后，只有后续官方发布更高版本才会再次提示；目前显示“暂无更新”是正常的。测试中出现的 2.6.2 是模拟夹具，不是已发布版本。

## 保留原数据和 AI 配置的升级步骤

1. 在原 App 保存编辑，导出 JSON 求职备份，并保存到 App 外的安全位置。附件原文件另行保管；JSON **不包含 API Key 和附件文件**，请自行安全保管密钥。
2. 下载并核对本版 APK，正常关闭原 App，打开 APK，在原应用上选择“更新”。不要先卸载、清除数据或重新配置 AI。
3. 更新后核对原公司、岗位、风险、附件关联与 AI 已配置状态，再使用更新检查。继续保留升级前备份。
4. 若 Android 提示签名不兼容或版本冲突，停止并保留旧版，记录版本与错误文字后反馈，不通过卸载或关闭防护强行继续。

本版与 2.6.0 使用同一应用 ID 和 Debug 签名；页面存储来源、数据库、AI 加密格式、Keystore 身份和安全文件位置保持兼容。设计为正常同签名覆盖更新时保留记录及 AI 配置，**尚未在真机完成保留结果和密钥解密验收，不能保证每款手机的升级结果**。换手机、卸载重装和清除数据不是覆盖升级；JSON 导入也不会恢复 AI 密钥。
