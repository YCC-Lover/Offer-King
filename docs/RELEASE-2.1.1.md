# Offer King 2.1.1 · AI 更好配，投递更好填

这一版保留投递跟进、Offer PK、薪资分析和城市预算，重点让 AI 从“需要研究怎么接入”变成“按指引配置、创建后补全、看清依据再保存”。本次公开更新包含 2.1.0 新功能与 2.1.1 体验修订。

[下载 Windows 2.1.1 安装包](https://github.com/YCC-Lover/Offer-King/releases/download/v2.1.1/Offer-King-Setup-2.1.1.exe) · [AI 配置与补全指南](https://github.com/YCC-Lover/Offer-King/blob/main/docs/AI-SETUP.md) · [图文上手](https://github.com/YCC-Lover/Offer-King/blob/main/docs/QUICKSTART.md)

无需 GitHub 或 App 账号，安装成功后即可手动管理投递；AI 是可选功能。没有内置共享密钥，也不需要先配置 AI 才能开始用。

## 本版值得试的变化

- **免费 AI 起步引导**：配置自己的 OpenRouter 与 Tavily 密钥，分别测试模型和搜索。免费额度及账户计费设置以服务商为准，不静默切换付费模型。
- **自己的模型自己选**：保存多套 OpenAI 兼容 Chat Completions、Responses 或本机 Ollama 配置；支持默认模型和按公司、岗位、风险分别指定。原有百炼和 DeepSeek 配置继续可用。
- **填公司和岗位，少做重复录入**：明确开启“创建岗位后自动调研”后，新记录保存成功再调研一次；默认关闭，普通重开不重复调用。
- **来源先核验，资料再保存**：核验通过的空白字段进入可编辑草稿；已有值和人工输入不被悄悄覆盖。不确定内容保留为建议，核对后点击“保存全部更改”才正式写入。
- **核对过程更连贯**：预填摘要可查看值、证据与来源，支持撤销；切换详情标签不丢建议，配置 AI 后可返回原岗位。歧义来源选择复用首轮证据，避免重复搜索。

AI 不代填阶段、优先级、联系人、下一事项、提醒、面试结果或个人备注；失败时已创建的投递仍保留。兼容接口不等于保证任何模型都能使用，普通模型联网调研还需要搜索服务。

## 三步开始

1. 安装并新增第一条投递；不用 AI 也能记录、筛选、跟进和比较。
2. 需要 AI 时进入“设置与备份 → AI 调研”，按[配置指南](https://github.com/YCC-Lover/Offer-King/blob/main/docs/AI-SETUP.md)设置自己的密钥，确认模型和搜索均可用。
3. 在岗位详情手动补全，或明确启用创建后自动调研；核对建议与来源，保存更改，定期导出 JSON 备份。

朋友首次安装从自己的空数据开始。只分享安装包和指南，不分享个人备份、数据目录或整个项目文件夹。

## 升级、隐私与试用提醒

旧用户建议先手动导出 JSON，关闭旧版后保留原安装位置覆盖安装，不要清空数据。保留原安装身份、数据位置和备份格式，不迁移或清空公司、岗位、风险、评分、附件路径或 AI 配置。

本机保存，没有云同步或遥测。公司图标会访问官网；AI 将允许的公司／岗位身份字段与公开证据交给实际选择的搜索和模型服务。开启自动调研后，新建岗位会触发这些请求；Ollama 联网调研也并非完全离线。附件只保存路径，备份不包含附件文件、模型配置或 API Key。详见[数据与隐私说明](https://github.com/YCC-Lover/Offer-King/blob/main/docs/PRIVACY.md)。

安装包**未签名**，Windows 可能提示未知发布者。请核对来源与 SHA-256，不要关闭 Defender 或 SmartScreen；持续拦截时先停止并反馈。哈希用于核对文件一致性，不等于安全认证。
