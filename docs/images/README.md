# 截图与演示数据说明

`00-brand.png` 是随应用使用的 Offer King 品牌图标，用于项目首页，逐字节复用现有品牌资源；它不是产品截图。下述版本和演示资料说明适用于界面截图。

基础功能截图（01–12）来自 Offer King 2.0.0 Windows 实际应用界面，使用 1440 × 1000 视口、100% 显示字号。浅色为主，另含深色模式截图；未重绘或拼接产品界面。`02-new-application.png` 与 `12-backup.png` 分别为原生表单弹窗、本地备份面板的元素截图，其余为完整视口截图。表单采用局部取景以避开隔离测试环境下的软件渲染背景模糊伪影；未修改实际表单。

新增 AI 截图（13–14）来自 **2.1.1 最终打包版** 的独立合成测试，完整视口为 1360 × 829；设置图为 100% 字号，预填图为 125% 字号。星河合成科技及测试工程师是虚构示例，预填使用模拟搜索和模型响应，不代表对真实公司的评价或线上 AI 实测效果。未读取真实资料或密钥，也没有发起付费调用。图中“待保存”内容仍是编辑草稿，不是已经正式保存。

截图中的星河科技、青禾创新、远山智能、云帆工作室、微光数据、拾光软件等名称均是虚构演示用名，不指代任何真实企业。所有岗位、流程、日期、薪酬、福利、评分与预算均为合成示例，不含真实求职记录、联系人或 API 密钥，也不构成企业评价、市场薪酬统计、税务计算或职业建议。

演示场景包含 3 份 Offer、2 家面试中公司、1 份已保存的个人 PK 方案和 3 份城市预算。新建岗位截图显示未提交的示例表单，不计入上述记录。年度税后现金收入由演示数据单独填写，不由税前年包自动推算。股票、公积金和现金的口径以界面说明为准。

截图在独立的一次性测试资料目录生成，未读取用户实际资料或密钥。采集期间阻断外部网络，不调用付费 AI。截图仅截取应用内容，不包含桌面、开发者工具或本地私有路径。
