## 第一次使用：不用一次学完

1. **先记一条投递。** [下载并校验安装包](DOWNLOAD.md)，再[填写公司与岗位](QUICKSTART.md#2-建立第一条投递)。无需应用账号；首次打开没有演示公司或作者资料。
2. **安排下一步。** 填好事项与时间，保存后从首页或全部待办查看；提醒在 App 内，不是后台系统闹钟。[跟进说明](QUICKSTART.md#3-让下一步有着落)
3. **有了待遇资料再比较。** [填写薪酬](QUICKSTART.md#5-先把薪酬的口径填对)、[准备城市预算](QUICKSTART.md#6-为城市生活留一份预算)，再做[双 Offer PK](QUICKSTART.md#7-做一次属于自己的双-offer-pk)。
4. **定期导出自己的备份。** 暂存草稿和本机自动备份都不能代替单独保管的 JSON；附件原文件需要另外保存。[备份说明](QUICKSTART.md#8-做好备份再慢慢完善)

AI 可以以后再配。2.5.4 的本机规则识别不调用 AI、不联网；AI 原文提取会交给所选模型，联网补全则另查公开来源，三条路线都需核对，未知信息不推测。到手工资也只在本机计算，不写回岗位或城市预算。

语言切换即时生效，并保留正在编辑的内容。公司、岗位、备注、人工阶段名和已有 AI 原文保持原样；默认阶段仅翻译显示，语言偏好只存在本机，不进入求职备份。

## 分享给朋友前

分享[项目首页](../README.md)、[下载中心](DOWNLOAD.md)和本页即可，不要分享个人数据目录、备份或密钥。下载无需 GitHub 账号；提交公开 Issue 需要账号。

安装包没有共享 AI Key。朋友使用自己的服务账户，免费额度及收费取决于服务商和账户设置；不使用 AI 时，本地记录功能仍可使用。公开反馈前请遮住姓名、联系方式、薪酬、私人路径及密钥。

本仓库仅用于闭源应用分发、文档与反馈，不提供应用源码。Release 页面自动生成的 `Source code` 压缩包不是安装包；请下载 `Offer-King-Setup-2.5.4.exe`。Windows 2.5.4 有前台新版检查，每天最多一次，只打开官方发布页、不自动下载安装；旧用户需先手动升级一次。安卓 Debug 不作为正式自动升级资产，GitHub 订阅也不等于 App 内提醒。
