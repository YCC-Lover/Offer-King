## 第一次来：三个入口就够了

1. **想先看看值不值得用：** [功能与界面导览](FEATURES.md)，了解投递跟进、公司决策与本地工具。截图逐张标注来源版本与合成资料，不冒充本轮安卓实拍。
2. **准备下载试用：** [下载中心](DOWNLOAD.md)提供双平台文件、签名边界、校验及[五项试用检查](DOWNLOAD.md#试用时先检查这五件事)；无需开发工具，下载无需 GitHub 账号。
3. **已经能打开：** 用一条虚构投递练习“录入 → 保存 → 关闭重开 → 备份”，再按需阅读[图文上手](QUICKSTART.md)。桌面截图不等于手机界面验收。

朋友各自在自己的设备开始；手机与电脑不自动同步，也不会共享你的记录或密钥。

## AI 可以以后再配

三条路线不要混淆：

- **本机规则识别：** 不调用模型、不联网，不需要密钥。
- **AI 原文提取：** 用模型分析你已经有的文字，不等于联网核实。
- **联网补全／调研：** 使用对应的模型与搜索路线，核对来源和时间，再采纳到草稿、明确保存。

安装包不含共享 API Key。“免费 AI 起步”需要自己的服务账户，额度、收费和可用性由服务商决定；连接测试也可能消耗额度。自动调研默认关闭，手机 localhost 指手机自己，不是电脑。[四语 AI 指南](AI-SETUP.md)

- **当前候选：** [2.6.0 功能与已测／未测说明](RELEASE-2.6.0.md)。[更新记录](../CHANGELOG.md)保留历史变化，[路线图](../ROADMAP.md)不代表发布日期承诺。
- **数据与隐私：** [资料保存、联网范围与密钥](PRIVACY.md)。普通记录与 JSON 不是加密保险箱；恢复草稿不替代独立备份，附件原文件与设备文档授权不随 JSON 迁移。
- **更新方式：** Windows 2.6.0 有前台新版检查，不自动下载或安装；2.4.0 及更早公开用户需先手动升级一次。安卓 Debug 不作为正式自动升级资产。
