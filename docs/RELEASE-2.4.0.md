## 粘贴一次，减少手工录入

在“新增投递”展开“粘贴招聘信息，减少手动填写”，复制同一家公司、同一岗位的招聘文字，点击“本机识别字段”。

- 预览建议、原文证据和不确定提示，只把勾选的空白项填入表单；现有输入保留。核对公司匹配与岗位后，明确点击创建才写入记录。
- 支持明确写出的公司、岗位、办公城市、链接、月薪区间、币种、薪数和岗位要求等。年薪、税后金额、多岗位冲突或未知待遇不强行猜填；仍可手动修正。
- 复用公司不修改其共享名称或官网，不把岗位办公城市推断成总部。完整原文仅在当前窗口内存中保留；已采纳的字段才可进入表单、恢复草稿及正式记录。
- **本机规则识别不调用 AI、不联网、不计费。** 它不是对招聘信息真实性的核实，也不保证识别所有格式。

原有岗位详情中的“粘贴招聘原文”仍是独立、可选的 **AI 提取**：需要已配置模型、明确费用与隐私同意。云端模型会收到你提交的文字，先移除敏感信息；不应与本机规则识别混淆。

## 独立“到手工资”页面

从主导航打开，也可在薪资分析或岗位薪酬中带入已保存的人民币月薪。默认优先取有效下限，可切换上限或手动修改。

- 城市自由选择或输入；高级参数分别调整养老、医疗、失业、公积金缴费基数和比例、医疗固定额及扣除项目。改城市不覆盖手填参数。
- 当前仅北京提供已核验的可选参考模板，必须明确点击应用才重置缴费参数；其他城市使用自定义，示例比例不代表当地或雇主政策。
- 显示首月、十二月、月均和全年到手，列出 12 个月个税与个人扣款。表格纵横滚动，表头和月份固定，支持键盘；大小字号与四语界面继续保留。
- 按**中国大陆居民个人、同一单位自一月起固定月薪 12 个月**模拟累计预扣。未处理年中入职、前单位累计、非居民或年度汇算；结果不是工资单、报税结果或专业税务意见。
- 不自动加入岗位 13/14 薪、股票、补贴、签字费或已填奖金。只有明确填写的本次奖金才计算；单位公积金单列参考，不加到现金。非人民币岗位不自动换汇。
- 缴费基数及税前扣除资格须按 HR、经办机构及官方政策核对；城市模板有适用期和来源，手填参数不证明全额可扣。

计算完全在本机进行，不调用 AI、不联网、不收费，不回写岗位或城市预算。普通页面往返保留本次试算；退出后不承诺恢复试算输入。

## 怎样获得后续更新？

当前 2.4.0 及之前版本 **没有 App 内新版推送、检查更新或自动下载安装**。发布新的 GitHub Release 不会改变已经安装的程序。请主动查看[下载中心](DOWNLOAD.md)，备份后手动下载升级。

GitHub 用户可在 Watch 中订阅 Releases，按其账户设置接收站内或邮件通知；这不是 App 内提醒。将来若增加版本提醒，旧用户也需要先手动升级一次到带提醒功能的版本。
