# 数据与隐私说明

[返回首页](../README.md) · [图文上手](QUICKSTART.md) · [AI 配置](AI-SETUP.md) · [常见问题](FAQ.md)

本文说明 **Offer King 2.1.1** 的实际数据边界。简单说：记录以本机保存为主，没有云同步或遥测；但公司图标、手动 AI 调研，以及你明确启用的“创建岗位后自动调研”会联网。本机保存不等于全部加密，也不等于从不向外部网站发送请求。

## 1. 哪些资料留在本机？

公司、岗位、流程、薪酬、个人评分、风险资料，以及已保存的 PK 方案、城市预算和最终选择，保存在当前电脑。当前没有应用账号、跨设备云同步或遥测，也不会自动上传你的求职数据库给作者。

本地还可能保留恢复草稿、公司图标缓存、显示偏好和备份。API Key 使用 Windows 安全存储加密；这不代表普通求职记录、草稿、缓存或导出的 JSON 都已加密。请把它们当作私人文件妥善保护。

附件记录只保存路径，不复制、上传附件文件本身。原文件移动或换电脑后，路径可能失效，需要重新选择。

## 2. 哪些操作会联网？

| 操作 | 发送 / 读取的内容 | 目的地与触发方式 |
| --- | --- | --- |
| 公司官网图标 | 已填写的公司官网地址；访问网站取得图标并在本机缓存 | 显示公司图标时可能访问对应公开网站，无需先启用 AI |
| 公司综合调研 | 公司名、官网、城市和行业等公司身份信息，以及取得的公开证据 | 你主动执行；使用该任务实际选定的服务。保留原策略时为百炼优先、DeepSeek 非联网分析兜底 |
| 岗位联网补全 | 公司名、公司官网、岗位名、岗位链接、城市，以及安全取得的公开网页文本与搜索证据 | 手动执行，或明确开启自动调研后在新岗位创建成功时执行；使用该任务实际选定的服务。保留原策略时使用 DeepSeek 官方联网接口 |
| 公司风险调研 | 公司名、官网、城市和行业，以及取得的公开证据 | 你主动执行；使用该任务实际选定的服务。保留原策略时使用 DeepSeek 官方联网接口 |
| Tavily 联网搜索 | 由上述公开公司／岗位身份字段构成的检索词 | 免费起步及普通自定义模型的联网调研会访问 Tavily；搜索结果再交给所选模型分析 |
| AI 测试与模型列表 | 对应测试或读取模型列表所需的请求及凭据；测试可能使用固定示例内容 | 你主动点击；发往配置的模型或搜索服务，可能消耗额度或计费 |
| 打开外部链接 | 由系统浏览器访问你打开的链接 | 你主动打开官网、招聘页面、服务商控制台等 |

AI 调研请求不包含联系人、私人备注、面试进度或附件内容。此边界按字段划分：如果你把敏感信息写进公司名、岗位名、官网 / 岗位链接等用于调研的字段，这些内容仍可能随请求发送。请只在这些字段填写适合交给对应外部服务处理的信息。

自定义云端模型会把请求和对应 API Key 发往你填写的公网 HTTPS 接口地址，请先确认地址归属与服务商可信度；不要把某家服务商的密钥填到不可信的另一地址。OpenRouter 会将模型请求路由至实际提供模型的服务方，请一并查看其数据处理说明。本机 Ollama 将模型请求交给本机运行的服务，但启用联网调研时 Tavily 搜索和公开网页访问仍会联网，不能称为完全离线。

如需本机推理，请选已下载的本地模型。本机服务若使用其云模型能力，请求仍可能由该服务转发到云端；连接回环地址不代表模型一定在本机运行。

“创建岗位后自动调研”默认关闭。明确启用并保存后，新建投递成功会触发外部请求，不会每次再询问；若不希望发生，请关闭并保存该开关。普通重开记录不自动重复调研，应用没有后台定时调研任务。

外部网站和模型服务商会按其自身规则处理收到的请求；Offer King 无法保证或代替它们的隐私、保留和计费政策。使用 AI 前，请自行阅读相应服务条款。即使不使用 AI，公司官网图标请求仍可能联网。

## 3. API Key 与费用

云端 AI 与搜索服务需要使用者配置自己的 API Key，安装包没有内置共享密钥；本机 Ollama 不要求云端模型密钥。模型与搜索密钥通过 Windows 安全存储加密保存，不进入求职数据库、JSON 备份或日志；界面不能读取完整的已保存密钥，新电脑需要重新配置。无法安全加密时，应用不会保存密钥。

不要通过 Issue、聊天截图、备注或备份共享密钥。如果怀疑密钥暴露，应到对应服务商处撤销并更换；只在本机移除配置不能撤销已泄露的密钥。

AI 调研和测试可能消耗额度或计费，包括启用后的创建自动调研。免费起步使用 OpenRouter 免费模型路由与 Tavily 普通搜索，不静默切换付费模型；免费额度、限流和是否计费取决于服务商政策及你的账户设置，应用不能替你关闭服务商按量计费。取消请求会停止应用继续处理，但不能保证退回服务商已经处理部分的额度或费用。

AI 输出仅是待核实的辅助资料，不自动等同事实。核验通过的空白字段可先进入可编辑草稿；正式写入仍需明确保存。“保存全部更改”不会自动采纳所有待选择的 AI 建议，取消或关闭预览也不等于撤销已加入的草稿。已采纳资料的来源、模型和查询时间会随正式流程记录留在本机，并进入记录备份。

## 4. 备份和草稿有什么区别？

| 内容 | 是否进入手动 JSON 求职备份 |
| --- | --- |
| 已保存的公司、岗位、薪酬、流程、评分和风险资料 | 是 |
| 已保存的 PK、城市预算及最终选择 | 是 |
| 附件路径 | 是；不是附件文件本身 |
| API Key、模型和搜索服务配置 | 否 |
| 尚未提交的临时恢复草稿、AI 预览 | 否 |
| 图标缓存与显示偏好 | 否 |

自动备份保存在本机，使用按日号轮换的槽位。它不是云备份，也不能抵御整机损坏。建议定期手动导出，放到由你选择并控制的安全位置。

新建、岗位、公司与流程表单有本地恢复草稿；它们是私人资料，不应公开。PK 和城市预算的未保存输入暂不支持异常重启恢复。草稿暂存与明确保存都不能替代独立备份。

## 5. 删除、导入与历史副本

在应用内删除记录，不等于清除了所有历史副本。导入前或部分删除操作前可能创建恢复快照，自动 / 手动备份也可能保留旧内容；磁盘上的原始附件不会随岗位删除。

如果你需要彻底处理某项私人资料，请同时考虑自己持有的手动导出、自动备份、恢复快照、截图和附件。操作前先确认具体文件与保留需求，不建议为了排错直接清空整个应用数据目录。

## 6. 公开反馈前，请再检查一遍

GitHub Issues、评论和附件通常公开可见。提交前请：

- 遮住姓名、电话、邮箱、联系人、私人薪酬、面试内容和文件路径。
- 不上传 API Key、完整 JSON 备份、原始数据目录或私人附件。
- 优先用虚构的公司和岗位复现问题。
- 如需诊断，使用应用内“帮助与关于 → 导出脱敏诊断”；文件仅用于提供版本、系统架构和预定义状态信息，发送前仍请自行查看。
