投了很多公司，记不清面试进度？拿到几份 Offer，却纠结该选哪一个？**Offer King** 是一款把投递跟进和 Offer 决策放在一起的 Windows 求职助手：用看板整理进度，拆解薪资组成，结合自己填写的城市生活预算，再按你看重的成长、待遇和工作生活平衡做一次双 Offer PK。

无需注册，不配置 AI 也能使用核心功能。你可以先留下一条投递，再随着面试进展慢慢补全信息；它帮你看清差异，最后的决定仍然交给你。

## 2.2.0 新版：待办看全，草稿可恢复，AI 少走弯路

- **全部待办，一次看全：** 逾期、今天、未来七天、以后和待安排时间分组查看；长列表可完整滚动，完成事项记录到流程，不自动改变阶段。
- **PK 与城市预算草稿可恢复：** 意外退出后，先预览未保存方案，再恢复到表单核对保存；不会用旧草稿静默覆盖已更新的正式记录。暂存不是备份。
- **粘贴招聘原文，提取到草稿：** 只需要岗位模型，不要求搜索密钥。选择有原文证据的职责、技能、薪酬等建议，再明确保存；所有建议默认不选，结果标明“未经联网核实”。
- **AI 一键检查：** 检查已保存的岗位补全配置、模型结构化输出和搜索来源；明确同意费用后才发测试请求，失败停止，并说明下一步。

原有“免费 AI 起步”、多模型配置及创建岗位后自动调研继续保留。没有共享密钥，不承诺免费额度；自动调研默认关闭，AI 内容仍需核对并保存。

## 下载后，能直接用吗？

安装成功后即可开始记录，不用下载源码，也不用安装 Node.js、Python 等开发工具。下载和使用 App 不需要 GitHub 账号。

- **手动记录就能用：** 投递看板、面试待办、薪酬分析、Offer 对比、城市预算和备份，不要求配置 AI。
- **每个人一份资料：** 数据保存在各自电脑，不带作者的记录或密钥，也不会与朋友同步。
- **AI 按需开启：** 使用时配置自己的 API Key，联网调用可能产生服务商费用，不影响你先用好本地功能。

## 它能帮你做什么？

| 你正在做的事 | 可以打开的页面 |
| --- | --- |
| 记住投了什么、下一次要做什么 | **首页 / 求职看板**：阶段卡片、待办与流程记录 |
| 整理拿到的 Offer，集中记录答复截止 | **我的 Offer**：收藏、决策状态、截止时间与个人最终选择 |
| 在两份机会之间认真做个比较 | **Offer 对比**：双 Offer PK、自定义指标、权重、评分和备注 |
| 看清工资、奖金、股票和签字费 | **薪资分析**：薪酬组成、常态年包与首年总包 |
| 考虑换城市之后的生活 | **城市生活**：自己填写收入和支出，保存不同预算方案 |
| 汇总公司资料和需要核实的风险 | **公司库 / 职业分析 / 风险看板**：个人评分、资料与来源 |
| 少填重复资料，先核对再保存 | **岗位详情 / AI 补全**：公开资料调研，或粘贴招聘原文提取；两种方式清楚区分 |

### 不只是“哪个数字更大”

![双 Offer PK：在自己的权重下比较条件与个人偏好](docs/images/04-offer-pk.png)

年包、成长、工作强度、城市偏好，可以有不同的重要程度。PK 允许你调整指标与权重，留下“为什么这样选”的备注。空白信息不会被当作零分，分数也不会替你自动选择公司。

![薪资分析：区分常态年包、签字费与薪酬组成](docs/images/05-salary.png)

常态年包不含签字费，首年总包单独看。绩效奖金、年终奖可以作为年度奖金的明细记录，不会重复计入；公积金和福利说明也不会被当作可自由支配的现金。

![城市生活：将自己的收入、租房与日常支出纳入预算](docs/images/06-city.png)

城市预算使用你填写的税后现金和生活成本，不冒充实时物价、税务计算或收入预测。一个岗位可以保存多种生活方案，再选择合适的一份参与 PK。

## 下载与安装

1. [下载 `Offer-King-Setup-2.2.0.exe`](https://github.com/YCC-Lover/Offer-King/releases/download/v2.2.0/Offer-King-Setup-2.2.0.exe)，或前往 [2.2.0 候选版发布页](https://github.com/YCC-Lover/Offer-King/releases/tag/v2.2.0) 的 **Assets** 下载同名文件、`SHA256.txt` 及 `START-HERE.txt`。页面上的 `Source code` 压缩包不是应用安装包。
2. 安装前阅读 [安装与校验说明](docs/QUICKSTART.md#1-下载并安装)。旧用户请先在应用内导出 JSON 备份，再关闭旧版。
3. 安装后打开 Offer King，点击“新增第一条投递”开始。无需注册，也不要求配置 AI。

**请先知道：2.2.0 是未签名的候选试用版本。** Windows 可能提示未知发布者；请核对来源和 SHA-256，遵循系统安全建议，不要关闭 Defender、SmartScreen 等防护。真实干净 Windows 首装与覆盖安装尚未验收；已通过的程序自动化测试不等于安装器验收。遇到拦截或异常请先停止并反馈。

当前提供 Windows x64 安装包；没有 macOS、Linux、Android 或 iOS 版，也没有自动更新功能。

## 第一次使用，先做这三件事

1. **留下一条记录。** 填写公司与岗位，选好阶段；不确定的选填信息可以以后补。
2. **安排下一步。** 在岗位详情填写“下一事项”和提醒时间，点击“保存全部更改”。提醒在应用内查看，不是系统后台闹钟。
3. **留一份备份。** 打开“设置与备份 → 数据备份 → 导出 JSON”，把文件放到自己选择的安全位置。

之后再按需要补充薪酬、试试 PK 和城市预算。[完整图文教程在这里 →](docs/QUICKSTART.md)

## 数据与 AI：把边界说清楚

- 求职记录保存在本机；当前没有云同步、账号系统或遥测。
- 核心记录、看板和比较功能不要求联网。公司官网图标会访问公开网站并缓存，所以“本机保存”不等于“绝不联网”。
- AI 是可选功能：手动发起，或在你明确开启后随新建岗位调研一次；默认不开启自动调研。需要你自己的 API Key，模型和搜索服务可能收费；连接测试也会访问对应服务。
- 免费起步使用服务商提供的免费模型与搜索额度，额度、可用性和账户计费设置以服务商为准；失败时不会静默切换收费模型。普通模型能连接，不代表联网搜索已配置。[配置与费用边界](docs/AI-SETUP.md)
- AI 联网调研按功能发送必要的公司 / 岗位信息，不主动读取联系人、私人备注、面试进度或附件内容。请勿把敏感内容填进公司名、岗位名或公开链接等调研字段。
- “粘贴招聘原文”会把你粘贴的文字交给所选模型；云端模型会收到这段文字，请先去除个人信息。它不搜索网页，也不核实真实性。完整原文不持久保存，但已采纳字段及有限证据摘录可以随草稿保留，正式保存后可进入记录备份。
- API Key 使用 Windows 安全存储加密，不进入 JSON 备份。普通求职记录、草稿和导出的备份**不是加密保险箱**。
- 附件只记录文件路径，JSON 备份不包含附件文件本身；换电脑时需要另外保管和迁移附件。

更多说明见 [数据与隐私](docs/PRIVACY.md)。AI 的结论、个人评分和财务试算都只是辅助信息，请核实后再使用。

## 现在还不完美的地方

- PK 与城市预算已支持本机恢复草稿，但容量有限，也不能保证保住突然断电前最后瞬间的输入。恢复到表单后仍需点击“保存方案 / 保存预算”，定期导出正式备份。
- 自动备份仍在同一台电脑，按日期槽位轮换，不能替代你自行保管的备份。
- 保存的 PK 会基于最新正式薪酬和所选预算重新计算，不是冻结的历史财务快照。
- 多币种不自动换汇；城市成本、税后收入和购房目标需要自己填写。

我们更希望把实际边界告诉你，而不是让你在用到一半时才发现。[查看常见问题](docs/FAQ.md) · [后续改进方向](ROADMAP.md)
