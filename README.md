## 你好，欢迎使用 Offer King

投了哪些公司？上次面试聊到哪一步？这份年包里，有多少是工资，有多少是奖金和股票？换一座城市之后，又能留下多少生活余地？

Offer King 是一款面向个人求职的 Windows 桌面工具。你可以先从一条投递开始，等信息逐渐完整，再比较条件、记录自己的取舍。不需要先搭表格，也不需要先配置 AI。

它负责帮你整理信息、看清差异；最后的决定，仍然交给你。

## 它能帮你做什么？

| 你正在做的事 | 可以打开的页面 |
| --- | --- |
| 记住投了什么、下一次要做什么 | **首页 / 求职看板**：阶段卡片、待办与流程记录 |
| 整理拿到的 Offer，不错过答复时间 | **我的 Offer**：收藏、决策状态、截止时间与个人最终选择 |
| 在两份机会之间认真做个比较 | **Offer 对比**：双 Offer PK、自定义指标、权重、评分和备注 |
| 看清工资、奖金、股票和签字费 | **薪资分析**：薪酬组成、常态年包与首年总包 |
| 考虑换城市之后的生活 | **城市生活**：自己填写收入和支出，保存不同预算方案 |
| 汇总公司资料和需要核实的风险 | **公司库 / 职业分析 / 风险看板**：个人评分、资料与来源 |

### 不只是“哪个数字更大”

![双 Offer PK：在自己的权重下比较条件与个人偏好](docs/images/04-offer-pk.png)

年包、成长、工作强度、城市偏好，可以有不同的重要程度。PK 允许你调整指标与权重，留下“为什么这样选”的备注。空白信息不会被当作零分，分数也不会替你自动选择公司。

![薪资分析：区分常态年包、签字费与薪酬组成](docs/images/05-salary.png)

常态年包不含签字费，首年总包单独看。绩效奖金、年终奖可以作为年度奖金的明细记录，不会重复计入；公积金和福利说明也不会被当作可自由支配的现金。

![城市生活：将自己的收入、租房与日常支出纳入预算](docs/images/06-city.png)

城市预算使用你填写的税后现金和生活成本，不冒充实时物价、税务计算或收入预测。一个岗位可以保存多种生活方案，再选择合适的一份参与 PK。

## 下载与安装

1. 前往 [Releases 发布页](https://github.com/YCC-Lover/Offer-King/releases/latest)，展开 **Assets**，选择 `Offer-King-Setup-2.0.0.exe`。页面上的 `Source code` 压缩包不是应用安装包。
2. 安装前阅读 [安装与校验说明](docs/QUICKSTART.md#1-下载并安装)。旧用户请先在应用内导出 JSON 备份，再关闭旧版。
3. 安装后打开 Offer King，点击“新增第一条投递”开始。无需注册，也不要求配置 AI。

**请先知道：2.0.0 是未签名的早期试用版本。** Windows 可能提示未知发布者；请核对来源和 SHA-256，遵循系统安全建议，不要关闭 Defender、SmartScreen 等防护。真实干净 Windows 环境中的首次安装与覆盖升级尚未完成验证，遇到拦截或异常请先停止并反馈。

当前提供 Windows x64 安装包；没有 macOS、Linux、Android 或 iOS 版，也没有自动更新功能。

## 第一次使用，先做这三件事

1. **留下一条记录。** 填写公司与岗位，选好阶段；不确定的选填信息可以以后补。
2. **安排下一步。** 在岗位详情填写“下一事项”和提醒时间，点击“保存全部更改”。提醒在应用内查看，不是系统后台闹钟。
3. **留一份备份。** 打开“设置与备份 → 数据备份 → 导出 JSON”，把文件放到自己选择的安全位置。

之后再按需要补充薪酬、试试 PK 和城市预算。[完整图文教程在这里 →](docs/QUICKSTART.md)

## 数据与 AI：把边界说清楚

- 求职记录保存在本机；当前没有云同步、账号系统或遥测。
- 核心记录、看板和比较功能不要求联网。公司官网图标会访问公开网站并缓存，所以“本机保存”不等于“绝不联网”。
- AI 是可选功能，只有主动操作时才会调用。需要你自己的 API Key，模型服务商可能收费；连接测试也应按可能产生费用看待。
- AI 调研按功能发送必要的公司 / 岗位信息，不上传联系人、私人备注、面试进度或附件内容。请勿把敏感内容填进公司名、岗位名或公开链接等调研字段。
- API Key 使用 Windows 安全存储加密，不进入 JSON 备份。普通求职记录、草稿和导出的备份**不是加密保险箱**。
- 附件只记录文件路径，JSON 备份不包含附件文件本身；换电脑时需要另外保管和迁移附件。

更多说明见 [数据与隐私](docs/PRIVACY.md)。AI 的结论、个人评分和财务试算都只是辅助信息，请核实后再使用。

## 现在还不完美的地方

- PK 与城市预算有正常离开保护，但未保存输入暂不支持异常重启恢复。请点击“保存方案 / 保存预算”。
- 自动备份仍在同一台电脑，按日期槽位轮换，不能替代你自行保管的备份。
- 保存的 PK 会基于最新正式薪酬和所选预算重新计算，不是冻结的历史财务快照。
- 多币种不自动换汇；城市成本、税后收入和购房目标需要自己填写。

我们更希望把实际边界告诉你，而不是让你在用到一半时才发现。[查看常见问题](docs/FAQ.md) · [后续改进方向](ROADMAP.md)
